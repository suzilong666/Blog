# 15-容器监控-cAdvisor-Prometheus-Grafana

随着容器数量增多，单靠手工看日志和进程状态，已经很难真正掌握系统运行情况。容器化环境下，CPU、内存、磁盘、网络、服务健康和响应延迟都会影响整体体验。如果没有监控机制，这些问题往往只能靠经验和猜测来定位。

cAdvisor、Prometheus 和 Grafana 这套组合，已经成为容器监控里最常见的实践。cAdvisor 负责采集容器级别的资源指标，Prometheus 负责把这些指标存储并提供查询能力，Grafana 则把这些结果以图表和仪表盘的形式展示出来。三者配合后，系统的可观测性会显著提升。

这套方案的优势，不在于“看上去很专业”，而在于它能把运行状态变成可以分析的数据。你可以很容易地看到某个容器的内存是否异常、某个服务的响应时延是否变高、某个节点的资源是否快要耗尽。对于生产环境，这些信息往往比直觉更重要。

如果你已经开始把应用容器化，监控就不应该是后面再补的事情，而应该作为基础设施的一部分提前规划。没有监控，就很难判断系统到底是健康、异常还是正在走向故障。对于任何有规模的容器环境而言，监控几乎是必备能力。
