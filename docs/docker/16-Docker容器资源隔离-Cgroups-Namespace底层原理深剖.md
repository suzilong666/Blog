# 16-Docker容器资源隔离-Cgroups-Namespace底层原理深剖

Docker 之所以看起来像一个轻量级虚拟机，根本原因在于它依赖了 Linux 内核提供的一系列机制。最核心的两个机制，就是 Namespace 和 Cgroups。它们分别解决了“隔离”和“资源限制”这两个问题，而这两个问题恰恰是容器技术成立的基础。

Namespace 负责把进程、网络、挂载点、用户和 IPC 等视图进行隔离。这样容器内部就会表现得像一个相对独立的环境，即使它依然运行在宿主机上。这个机制让容器具备了基础隔离能力，同时又不需要为每个应用虚拟一整套操作系统。

Cgroups 则负责对资源使用进行控制。它可以限制容器对 CPU、内存、磁盘 I/O 和网络带宽的占用，避免某个实例因为异常行为把宿主机的资源耗尽。对于多容器共享同一台机器的场景来说，这种限制机制非常关键。

如果没有 Namespace，容器就很难拥有独立的运行视图；如果没有 Cgroups，容器就很难在共享环境中安全运行。正是这两者的结合，才让 Docker 既轻量，又能提供一定程度的隔离和可控性。要真正理解 Docker 的底层原理，Namespace 和 Cgroups 是必须重点研究的内容。
