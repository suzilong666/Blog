# 02-零基础Docker极速入门-10分钟跑起你的第一个Nginx容器

想真正理解 Docker，最好的起点不是复杂的微服务，而是一个最简单、最经典的例子：用 Nginx 启动一个容器。Nginx 的价值在于，它足够轻量，又足够常见，正适合作为初学者建立“镜像、容器、端口映射”认知的起点。

第一步是拉取镜像。镜像可以理解为容器运行所依赖的模板。官方的 Nginx 镜像已经为你准备好了运行环境，你只需要执行下面这条命令：

```bash
docker pull nginx
```

第二步是启动容器。Docker 的核心动作之一，就是把镜像实例化为一个运行中的容器。下面的命令把宿主机的 8080 端口映射到容器内的 80 端口，这样你就能通过浏览器直接访问容器内服务：

```bash
docker run -d --name my-nginx -p 8080:80 nginx
```

第三步就是访问页面。打开浏览器，访问 `http://localhost:8080`，如果一切正常，你将看到 Nginx 的默认欢迎页。这意味着你的容器已经成功运行，并且服务已经被暴露到了宿主机。

很多初学者会误以为 Docker 就是“把程序放到一个盒子里跑”。其实更准确地说，Docker 让应用在一个相对隔离、相对可控的环境里执行。你看到的端口映射、容器名称、容器日志，都是学习容器化过程中的关键点。只有把这个最简流程真正跑通，后面再去理解 Docker Compose、数据卷、镜像构建和资源限制，才会顺得多。

学习 Docker 最容易忽略的地方，不是命令本身，而是“为什么这么做”。只要你能够把“拉镜像、跑容器、访问服务”三件事串起来，就已经建立了一个很扎实的入门基础。
