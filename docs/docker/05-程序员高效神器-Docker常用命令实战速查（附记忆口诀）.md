# 05-程序员高效神器-Docker常用命令实战速查（附记忆口诀）

Docker 的命令行看起来很多，初学者最容易被命令数量吓住。但真正日常使用中，最值得掌握的其实并不多。只要你把镜像、容器、日志、网络和数据卷这几类命令理解透，基本就能应对绝大多数开发和排查场景。

最常用的命令可以分为五类：镜像管理、容器管理、日志与调试、网络管理和数据卷管理。镜像管理包括 `pull`、`images`、`rmi`；容器管理包括 `run`、`ps`、`stop`、`rm`；日志与调试包括 `logs`、`exec`、`inspect`。这些命令是你在入门阶段最应该反复练习的内容。

下面是几条非常常见的命令：

```bash
docker images
docker ps -a
docker run -d --name app -p 8080:80 nginx
docker logs app
docker exec -it app /bin/sh
```

它们分别对应了“查看镜像、查看容器、启动容器、查看日志、进入容器”。如果容器启动失败，先看日志；如果端口没通，先检查端口映射；如果应用异常，先进入容器看运行环境。掌握这套思路之后，你排查问题的效率会显著提高。

为了方便记忆，很多人会用一组口诀来串联这几条基础命令：看镜像用 `images`，看容器用 `ps`，拉镜像用 `pull`，起容器用 `run`，看日志用 `logs`，进容器用 `exec`。这不是“死记硬背”，而是帮助你迅速建立命令与场景之间的关联。
