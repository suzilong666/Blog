# Java 设计模式

设计模式是解决常见问题的最佳实践。本文将详细讲解 23 种经典设计模式在 Java 中的实现与应用。

## 设计模式概述

### 什么是设计模式

设计模式是从大量实践中总结出来的代码设计经验，用于解决特定场景下的设计问题。

## 创建型模式

### 单例模式（Singleton）

```java
/**
 * 单例模式：确保一个类只有一个实例
 */
public class SingletonPattern {
    
    // 方式一：饿汉式
    public static class EagerSingleton {
        private static final EagerSingleton INSTANCE = new EagerSingleton();
        
        private EagerSingleton() {}
        
        public static EagerSingleton getInstance() {
            return INSTANCE;
        }
    }
    
    // 方式二：双重检查锁（推荐）
    public static class DCLSingleton {
        private static volatile DCLSingleton instance;
        
        private DCLSingleton() {}
        
        public static DCLSingleton getInstance() {
            if (instance == null) {
                synchronized (DCLSingleton.class) {
                    if (instance == null) {
                        instance = new DCLSingleton();
                    }
                }
            }
            return instance;
        }
    }
    
    // 方式三：静态内部类（推荐）
    public static class HolderSingleton {
        private HolderSingleton() {}
        
        private static class Holder {
            private static final HolderSingleton INSTANCE = new HolderSingleton();
        }
        
        public static HolderSingleton getInstance() {
            return Holder.INSTANCE;
        }
    }
    
    // 方式四：枚举（最安全）
    public enum EnumSingleton {
        INSTANCE;
        
        private String data;
        
        public String getData() { return data; }
        public void setData(String data) { this.data = data; }
    }
}
```

### 工厂方法模式（Factory Method）

```java
/**
 * 工厂方法模式：定义创建对象的接口，由子类决定实例化哪个类
 */
public class FactoryMethodPattern {
    
    // 产品接口
    public interface Product {
        void use();
    }
    
    // 具体产品
    public static class ConcreteProductA implements Product {
        @Override
        public void use() {
            System.out.println("使用产品 A");
        }
    }
    
    public static class ConcreteProductB implements Product {
        @Override
        public void use() {
            System.out.println("使用产品 B");
        }
    }
    
    // 工厂接口
    public interface Factory {
        Product createProduct();
    }
    
    // 具体工厂
    public static class FactoryA implements Factory {
        @Override
        public Product createProduct() {
            return new ConcreteProductA();
        }
    }
    
    public static class FactoryB implements Factory {
        @Override
        public Product createProduct() {
            return new ConcreteProductB();
        }
    }
    
    // 使用示例
    public static void main(String[] args) {
        Factory factoryA = new FactoryA();
        Product productA = factoryA.createProduct();
        productA.use();
        
        Factory factoryB = new FactoryB();
        Product productB = factoryB.createProduct();
        productB.use();
    }
}
```

### 建造者模式（Builder）

```java
/**
 * 建造者模式：将复杂对象的构建与其表示分离
 */
public class BuilderPattern {
    
    // 产品类
    public static class Computer {
        private final String cpu;
        private final String motherboard;
        private final int memory;
        private final int storage;
        private final boolean hasGPU;
        
        private Computer(Builder builder) {
            this.cpu = builder.cpu;
            this.motherboard = builder.motherboard;
            this.memory = builder.memory;
            this.storage = builder.storage;
            this.hasGPU = builder.hasGPU;
        }
        
        // Builder 类
        public static class Builder {
            private String cpu;
            private String motherboard;
            private int memory = 8;
            private int storage = 256;
            private boolean hasGPU = false;
            
            public Builder cpu(String cpu) {
                this.cpu = cpu;
                return this;
            }
            
            public Builder motherboard(String motherboard) {
                this.motherboard = motherboard;
                return this;
            }
            
            public Builder memory(int memory) {
                this.memory = memory;
                return this;
            }
            
            public Builder storage(int storage) {
                this.storage = storage;
                return this;
            }
            
            public Builder hasGPU(boolean hasGPU) {
                this.hasGPU = hasGPU;
                return this;
            }
            
            public Computer build() {
                // 参数校验
                if (cpu == null || motherboard == null) {
                    throw new IllegalArgumentException("CPU 和主板不能为空");
                }
                return new Computer(this);
            }
        }
        
        @Override
        public String toString() {
            return "Computer{cpu='" + cpu + "', memory=" + memory + "GB, storage=" + storage + "GB}";
        }
    }
    
    // 使用示例
    public static void main(String[] args) {
        Computer gamingPC = new Computer.Builder()
            .cpu("Intel i9-13900K")
            .motherboard("ASUS ROG")
            .memory(32)
            .storage(1024)
            .hasGPU(true)
            .build();
        
        Computer officePC = new Computer.Builder()
            .cpu("Intel i5-13400")
            .motherboard("MSI B760")
            .memory(16)
            .storage(512)
            .build();
        
        System.out.println(gamingPC);
        System.out.println(officePC);
    }
}
```

## 结构型模式

### 适配器模式（Adapter）

```java
/**
 * 适配器模式：将一个类的接口转换成客户希望的另一个接口
 */
public class AdapterPattern {
    
    // 目标接口
    public interface Target {
        void request();
    }
    
    // 被适配的类（Adaptee）
    public static class Adaptee {
        public void specificRequest() {
            System.out.println("Adaptee: 特殊请求");
        }
    }
    
    // 类适配器（继承方式）
    public static class ClassAdapter extends Adaptee implements Target {
        @Override
        public void request() {
            specificRequest();  // 调用父类方法
        }
    }
    
    // 对象适配器（组合方式，更灵活）
    public static class ObjectAdapter implements Target {
        private final Adaptee adaptee;
        
        public ObjectAdapter(Adaptee adaptee) {
            this.adaptee = adaptee;
        }
        
        @Override
        public void request() {
            adaptee.specificRequest();  // 委托调用
        }
    }
    
    // 使用示例
    public static void main(String[] args) {
        Adaptee adaptee = new Adaptee();
        
        Target adapter1 = new ClassAdapter();
        adapter1.request();
        
        Target adapter2 = new ObjectAdapter(adaptee);
        adapter2.request();
    }
}
```

### 代理模式（Proxy）

```java
import java.lang.reflect.InvocationHandler;
import java.lang.reflect.Method;
import java.lang.reflect.Proxy;

/**
 * 代理模式：为对象提供代理，控制对对象的访问
 */
public class ProxyPattern {
    
    // 主题接口
    public interface Service {
        void execute();
    }
    
    // 真实主题
    public static class RealService implements Service {
        @Override
        public void execute() {
            System.out.println("真实服务执行操作");
        }
    }
    
    // 静态代理
    public static class StaticProxy implements Service {
        private final Service realService;
        
        public StaticProxy(Service realService) {
            this.realService = realService;
        }
        
        @Override
        public void execute() {
            System.out.println("前置处理");
            realService.execute();
            System.out.println("后置处理");
        }
    }
    
    // JDK 动态代理
    public static class DynamicProxy implements InvocationHandler {
        private final Object target;
        
        public DynamicProxy(Object target) {
            this.target = target;
        }
        
        @Override
        public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
            System.out.println("方法 " + method.getName() + " 调用前");
            Object result = method.invoke(target, args);
            System.out.println("方法 " + method.getName() + " 调用后");
            return result;
        }
        
        // 创建代理实例
        @SuppressWarnings("unchecked")
        public static <T> T createProxy(T target, Class<T> interfaceType) {
            return (T) Proxy.newProxyInstance(
                target.getClass().getClassLoader(),
                new Class<?>[]{interfaceType},
                new DynamicProxy(target)
            );
        }
    }
    
    // 使用示例
    public static void main(String[] args) {
        Service realService = new RealService();
        
        // 静态代理
        Service staticProxy = new StaticProxy(realService);
        staticProxy.execute();
        
        // 动态代理
        Service dynamicProxy = DynamicProxy.createProxy(realService, Service.class);
        dynamicProxy.execute();
    }
}
```

### 装饰器模式（Decorator）

```java
/**
 * 装饰器模式：动态地给对象添加额外的职责
 */
public class DecoratorPattern {
    
    // 组件接口
    public interface Coffee {
        double cost();
        String description();
    }
    
    // 具体组件
    public static class Espresso implements Coffee {
        @Override
        public double cost() {
            return 1.5;
        }
        
        @Override
        public String description() {
            return "浓缩咖啡";
        }
    }
    
    public static class PlainCoffee implements Coffee {
        @Override
        public double cost() {
            return 1.0;
        }
        
        @Override
        public String description() {
            return "美式咖啡";
        }
    }
    
    // 装饰器抽象类
    public abstract static class CoffeeDecorator implements Coffee {
        protected final Coffee decoratedCoffee;
        
        public CoffeeDecorator(Coffee coffee) {
            this.decoratedCoffee = coffee;
        }
    }
    
    // 具体装饰器
    public static class MilkDecorator extends CoffeeDecorator {
        public MilkDecorator(Coffee coffee) {
            super(coffee);
        }
        
        @Override
        public double cost() {
            return decoratedCoffee.cost() + 0.3;
        }
        
        @Override
        public String description() {
            return decoratedCoffee.description() + " + 牛奶";
        }
    }
    
    public static class SugarDecorator extends CoffeeDecorator {
        public SugarDecorator(Coffee coffee) {
            super(coffee);
        }
        
        @Override
        public double cost() {
            return decoratedCoffee.cost() + 0.1;
        }
        
        @Override
        public String description() {
            return decoratedCoffee.description() + " + 糖";
        }
    }
    
    // 使用示例
    public static void main(String[] args) {
        Coffee espresso = new Espresso();
        System.out.println(espresso.description() + ": $" + espresso.cost());
        
        Coffee latte = new MilkDecorator(new Espresso());
        System.out.println(latte.description() + ": $" + latte.cost());
        
        Coffee sweetLatte = new SugarDecorator(new MilkDecorator(new Espresso()));
        System.out.println(sweetLatte.description() + ": $" + sweetLatte.cost());
    }
}
```

## 行为型模式

### 策略模式（Strategy）

```java
/**
 * 策略模式：定义一系列算法，把它们独立封装，可以互换
 */
public class StrategyPattern {
    
    // 策略接口
    public interface PaymentStrategy {
        void pay(double amount);
    }
    
    // 具体策略
    public static class CreditCardPayment implements PaymentStrategy {
        @Override
        public void pay(double amount) {
            System.out.println("信用卡支付: $" + amount);
        }
    }
    
    public static class AlipayPayment implements PaymentStrategy {
        @Override
        public void pay(double amount) {
            System.out.println("支付宝支付: $" + amount);
        }
    }
    
    public static class WeChatPayment implements PaymentStrategy {
        @Override
        public void pay(double amount) {
            System.out.println("微信支付: $" + amount);
        }
    }
    
    // 上下文类
    public static class ShoppingCart {
        private PaymentStrategy paymentStrategy;
        
        public void setPaymentStrategy(PaymentStrategy strategy) {
            this.paymentStrategy = strategy;
        }
        
        public void checkout(double total) {
            if (paymentStrategy == null) {
                throw new IllegalStateException("请选择支付方式");
            }
            paymentStrategy.pay(total);
        }
    }
    
    // 使用示例
    public static void main(String[] args) {
        ShoppingCart cart = new ShoppingCart();
        
        cart.setPaymentStrategy(new CreditCardPayment());
        cart.checkout(99.99);
        
        cart.setPaymentStrategy(new AlipayPayment());
        cart.checkout(99.99);
        
        cart.setPaymentStrategy(new WeChatPayment());
        cart.checkout(99.99);
    }
}
```

### 观察者模式（Observer）

```java
import java.util.ArrayList;
import java.util.List;

/**
 * 观察者模式：定义对象间的一对多依赖关系
 */
public class ObserverPattern {
    
    // 主题接口
    public interface Subject {
        void registerObserver(Observer observer);
        void removeObserver(Observer observer);
        void notifyObservers();
    }
    
    // 观察者接口
    public interface Observer {
        void update(String message);
    }
    
    // 具体主题
    public static class NewsAgency implements Subject {
        private final List<Observer> observers = new ArrayList<>();
        private String news;
        
        @Override
        public void registerObserver(Observer observer) {
            observers.add(observer);
        }
        
        @Override
        public void removeObserver(Observer observer) {
            observers.remove(observer);
        }
        
        @Override
        public void notifyObservers() {
            for (Observer observer : observers) {
                observer.update(news);
            }
        }
        
        public void setNews(String news) {
            this.news = news;
            notifyObservers();  // 状态变化时通知
        }
    }
    
    // 具体观察者
    public static class NewsChannel implements Observer {
        private final String channelName;
        
        public NewsChannel(String channelName) {
            this.channelName = channelName;
        }
        
        @Override
        public void update(String message) {
            System.out.println(channelName + " 收到新闻: " + message);
        }
    }
    
    // 使用示例
    public static void main(String[] args) {
        NewsAgency agency = new NewsAgency();
        
        NewsChannel channel1 = new NewsChannel("CNN");
        NewsChannel channel2 = new NewsChannel("BBC");
        NewsChannel channel3 = new NewsChannel("CCTV");
        
        agency.registerObserver(channel1);
        agency.registerObserver(channel2);
        agency.registerObserver(channel3);
        
        agency.setNews("重大新闻事件发生！");
        
        agency.removeObserver(channel2);
        agency.setNews("第二条新闻");
    }
}
```

### 模板方法模式（Template Method）

```java
/**
 * 模板方法模式：定义算法骨架，将某些步骤延迟到子类实现
 */
public class TemplateMethodPattern {
    
    // 抽象模板类
    public abstract static class DataProcessor {
        
        // 模板方法（定义执行流程）
        public final void process() {
            loadData();
            validateData();
            transformData();
            saveData();
            notify();
        }
        
        // 基本方法（已实现）
        protected void validateData() {
            System.out.println("验证数据...");
        }
        
        protected void notify() {
            System.out.println("发送通知");
        }
        
        // 抽象方法（子类实现）
        protected abstract void loadData();
        protected abstract void transformData();
        protected abstract void saveData();
    }
    
    // CSV 数据处理器
    public static class CsvProcessor extends DataProcessor {
        @Override
        protected void loadData() {
            System.out.println("从 CSV 文件加载数据");
        }
        
        @Override
        protected void transformData() {
            System.out.println("转换 CSV 格式");
        }
        
        @Override
        protected void saveData() {
            System.out.println("保存到数据库");
        }
    }
    
    // JSON 数据处理器
    public static class JsonProcessor extends DataProcessor {
        @Override
        protected void loadData() {
            System.out.println("从 API 加载 JSON 数据");
        }
        
        @Override
        protected void transformData() {
            System.out.println("转换 JSON 格式");
        }
        
        @Override
        protected void saveData() {
            System.out.println("保存到数据仓库");
        }
        
        @Override
        protected void notify() {
            System.out.println("发送消息队列通知");
        }
    }
    
    // 使用示例
    public static void main(String[] args) {
        DataProcessor csvProcessor = new CsvProcessor();
        csvProcessor.process();
        
        System.out.println("---");
        
        DataProcessor jsonProcessor = new JsonProcessor();
        jsonProcessor.process();
    }
}
```

## 模式选择指南

### 常用场景与模式匹配

| 场景 | 推荐模式 | 原因 |
|------|----------|------|
| 只需要一个实例 | Singleton | 保证唯一性 |
| 创建复杂对象 | Builder | 简化创建过程 |
| 对象创建逻辑 | Factory Method | 解耦创建与使用 |
| 需要扩展功能 | Decorator | 动态添加功能 |
| 控制对象访问 | Proxy | 增加间接层 |
| 多种算法切换 | Strategy | 易于扩展和切换 |
| 事件通知机制 | Observer | 解耦发布者和订阅者 |
| 固定执行流程 | Template Method | 定义算法骨架 |

### 模式组合使用

```java
public class PatternCombination {
    
    // 示例：订单系统使用多种模式
    public class OrderSystem {
        
        // 1. 策略模式：支付方式
        private final Map<String, PaymentStrategy> paymentStrategies = new HashMap<>();
        
        // 2. 工厂模式：创建订单
        private final OrderFactory orderFactory;
        
        // 3. 观察者模式：订单状态变化通知
        private final List<OrderObserver> observers = new ArrayList<>();
        
        // 4. 模板方法：订单处理流程
        public void processOrder(Order order) {
            validateOrder(order);      // 模板方法
            createOrder(order);        // 工厂模式
            payOrder(order);           // 策略模式
            notifyObservers(order);   // 观察者模式
        }
        
        private void validateOrder(Order order) {
            // 验证逻辑
        }
        
        private void createOrder(Order order) {
            orderFactory.create(order);
        }
        
        private void payOrder(Order order) {
            PaymentStrategy strategy = paymentStrategies.get(order.getPaymentType());
            strategy.pay(order.getAmount());
        }
        
        private void notifyObservers(Order order) {
            for (OrderObserver observer : observers) {
                observer.update(order);
            }
        }
    }
}
```
