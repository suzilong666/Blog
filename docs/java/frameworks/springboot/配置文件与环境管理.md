# 配置文件与环境管理

## 一、配置文件概述

### 1.1 配置文件类型

SpringBoot支持两种配置文件格式：

| 格式 | 文件 | 优点 | 缺点 |
|------|------|------|------|
| **Properties** | `application.properties` | 简单直接，Java原生支持 | 层级不直观 |
| **YAML** | `application.yml` | 层级清晰，可读性好 | 需要额外依赖 |

### 1.2 配置文件位置

SpringBoot按优先级从高到低加载配置文件：

```
1. 命令行参数         java -jar app.jar --server.port=9090
2. JNDI属性
3. 操作系统环境变量
4. application-{profile}.{properties|yml} （当前目录/config子目录）
5. application-{profile}.{properties|yml} （当前目录）
6. application.{properties|yml} （当前目录/config子目录）
7. application.{properties|yml} （当前目录）
8. application-{profile}.{properties|yml} （classpath:/config/）
9. application-{profile}.{properties|yml} （classpath:/）
10. application.{properties|yml} （classpath:/config/）
11. application.{properties|yml} （classpath:/）
12. @PropertySource注解
13. 默认属性
```

## 二、Properties配置

### 2.1 基本语法

```properties
# 注释使用 # 或 !

# 简单键值对
server.port=8080
server.servlet.context-path=/api

# 多级配置使用 . 分隔
spring.datasource.url=jdbc:mysql://localhost:3306/example
spring.datasource.username=root
spring.datasource.password=password

# 列表配置
spring.profiles.active=dev,test

# 数值配置
spring.datasource.hikari.maximum-pool-size=20
spring.datasource.hikari.minimum-idle=5

# 布尔值
spring.jpa.show-sql=true
spring.cache.enabled=false
```

### 2.2 占位符

```properties
# 使用 ${} 引用其他配置
app.name=MyApplication
app.description=${app.name} is a SpringBoot application

# 使用默认值
app.version=${APP_VERSION:1.0.0}

# 使用系统属性
app.java.version=${java.version}

# 使用环境变量
app.path=${APP_HOME:/opt/app}
```

### 2.3 特殊字符处理

```properties
# 需要转义的字符
# : \ = 等特殊字符
app.password=pass\:word
app.path=C\\:\\Program Files\\App
app.name=My=Application

# 或者使用引号
app.password="pass:word"
app.name='My=Application'

# 多行值
app.description=This is a \
  long description \
  that spans multiple lines
```

## 三、YAML配置

### 3.1 基本语法

```yaml
# YAML配置
server:
  port: 8080
  servlet:
    context-path: /api

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/example
    username: root
    password: password
    hikari:
      maximum-pool-size: 20
      minimum-idle: 5

# 列表
spring:
  profiles:
    active:
      - dev
      - test

# 映射
app:
  config:
    key1: value1
    key2: value2
    key3: value3

# 布尔值
spring:
  jpa:
    show-sql: true
```

### 3.2 YAML特性

```yaml
# 1. 引用变量（使用 ${}）
app:
  name: MyApplication
  description: ${app.name} is a SpringBoot application

# 2. 锚点和复用
logging:
  level: &logLevel
    root: INFO
    com.example: DEBUG

# 3. 合并配置
application:
  <<: *logLevel

# 4. 多文档
---
spring:
  config:
    activate:
      on-profile: dev
server:
  port: 8080
---
spring:
  config:
    activate:
      on-profile: prod
server:
  port: 9090
```

### 3.3 YAML vs Properties选择

| 场景 | 推荐 | 原因 |
|------|------|------|
| 简单配置 | Properties | 易于维护 |
| 复杂层级 | YAML | 结构清晰 |
| 列表/映射 | YAML | 语法简洁 |
| 多环境 | YAML | 多文档方便 |
| 团队协作 | YAML | 可读性好 |

## 四、多环境配置

### 4.1 Profile概念

**Profile** 是Spring中用于区分不同**运行环境**的机制，常见的环境包括：

- **dev**：开发环境
- **test**：测试环境
- **staging**：预发布环境
- **prod**：生产环境

### 4.2 创建多环境配置文件

```
src/main/resources/
├── application.yml           # 主配置（通用）
├── application-dev.yml       # 开发环境
├── application-test.yml      # 测试环境
├── application-staging.yml   # 预发布环境
└── application-prod.yml      # 生产环境
```

#### 主配置文件

```yaml
# application.yml
spring:
  application:
    name: demo-service
  
  # 激活的profile
  profiles:
    active: ${SPRING_PROFILES_ACTIVE:dev}
  
  # 通用配置（所有环境共享）
  jackson:
    date-format: yyyy-MM-dd HH:mm:ss
    time-zone: Asia/Shanghai

# 日志配置（通用）
logging:
  level:
    com.example.demo: DEBUG
```

#### 开发环境配置

```yaml
# application-dev.yml
server:
  port: 8080

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/example_dev
    username: root
    password: root
    hikari:
      maximum-pool-size: 5
      minimum-idle: 2

# 开发环境专用配置
app:
  debug: true
  cache:
    enabled: false
  features:
    - debug-panel
    - swagger-ui
```

#### 生产环境配置

```yaml
# application-prod.yml
server:
  port: 8080

spring:
  datasource:
    url: jdbc:mysql://prod-host:3306/example_prod
    username: ${DB_USERNAME}
    password: ${DB_PASSWORD}
    hikari:
      maximum-pool-size: 50
      minimum-idle: 10
      connection-timeout: 30000
      idle-timeout: 600000

# 生产环境专用配置
app:
  debug: false
  cache:
    enabled: true
  features:
    - monitoring
    - rate-limiting

# 生产环境日志配置
logging:
  level:
    com.example.demo: INFO
  file:
    name: /var/log/app/application.log
  rollingpolicy:
    max-file-size: 100MB
    max-history: 30
```

### 4.3 激活指定Profile

#### 配置文件方式

```yaml
# application.yml
spring:
  profiles:
    active: dev  # 激活开发环境
```

#### 命令行参数

```bash
# 运行时指定
java -jar app.jar --spring.profiles.active=prod

# 或者指定多个profile
java -jar app.jar --spring.profiles.active=prod,feature1
```

#### 环境变量

```bash
# Linux/Mac
export SPRING_PROFILES_ACTIVE=prod
java -jar app.jar

# Windows
set SPRING_PROFILES_ACTIVE=prod
java -jar app.jar
```

#### 启动类设置

```java
@SpringBootApplication
public class DemoApplication {
    
    public static void main(String[] args) {
        // 编程方式设置profile
        SpringApplication app = new SpringApplication(DemoApplication.class);
        app.setAdditionalProfiles("dev");
        app.run(args);
    }
}
```

### 4.4 Profile条件装配

```java
@Configuration
public class ProfileConfig {
    
    @Bean
    @Profile("dev")
    public DataSource devDataSource() {
        // 开发环境数据源
        HikariDataSource dataSource = new HikariDataSource();
        dataSource.setJdbcUrl("jdbc:mysql://localhost:3306/dev");
        dataSource.setUsername("dev_user");
        dataSource.setPassword("dev_password");
        return dataSource;
    }
    
    @Bean
    @Profile("prod")
    public DataSource prodDataSource() {
        // 生产环境数据源
        HikariDataSource dataSource = new HikariDataSource();
        dataSource.setJdbcUrl("jdbc:mysql://prod-host:3306/prod");
        dataSource.setUsername("prod_user");
        dataSource.setPassword("prod_password");
        return dataSource;
    }
    
    @Bean
    @Profile({"dev", "test"})
    public DataSource testDataSource() {
        // 测试环境数据源
        HikariDataSource dataSource = new HikariDataSource();
        dataSource.setJdbcUrl("jdbc:h2:mem:testdb");
        return dataSource;
    }
}
```

## 五、配置属性绑定

### 5.1 @Value注解

```java
// 使用@Value注入单个配置项
@Service
public class UserService {
    
    @Value("${app.name}")
    private String appName;
    
    @Value("${app.version:1.0.0}")  // 带默认值
    private String appVersion;
    
    @Value("${spring.datasource.url}")
    private String datasourceUrl;
    
    @Value("${app.features:}")
    private String[] features;
    
    @Value("#{systemProperties['java.version']}")  // SpEL表达式
    private String javaVersion;
}
```

### 5.2 @ConfigurationProperties

```java
// 类型安全的配置绑定
@Data
@Component
@ConfigurationProperties(prefix = "app")
public class AppProperties {
    
    private String name = "MyApplication";
    private String version = "1.0.0";
    private String description;
    private Author author = new Author();
    private List<String> features = new ArrayList<>();
    private Map<String, String> metadata = new HashMap<>();
    private Security security = new Security();
    
    @Data
    public static class Author {
        private String name;
        private String email;
        private String url;
    }
    
    @Data
    public static class Security {
        private boolean enabled = true;
        private String secretKey;
        private List<String> allowedOrigins;
    }
}

// 对应配置文件
# application.yml
app:
  name: MyApplication
  version: 1.0.0
  description: A demo application
  author:
    name: John Doe
    email: john@example.com
    url: https://example.com
  features:
    - user-management
    - order-management
    - payment
  metadata:
    environment: production
    region: cn
  security:
    enabled: true
    secret-key: my-secret-key-123
    allowed-origins:
      - http://localhost:3000
      - https://example.com
```

### 5.3 第三方配置属性

```java
// 使用EnableConfigurationProperties启用第三方配置类
@Configuration
@EnableConfigurationProperties(RedisProperties.class)
public class CustomRedisConfig {
    
    @Bean
    public RedisTemplate<String, Object> redisTemplate(
            RedisProperties properties,
            LettuceConnectionFactory connectionFactory) {
        
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(connectionFactory);
        
        // 使用properties配置
        template.setDefaultSerializer(new GenericJackson2JsonRedisSerializer());
        
        return template;
    }
}
```

## 六、配置文件加载优先级

### 6.1 外部化配置

```
┌─────────────────────────────────────────────────────────────┐
│                  配置加载优先级（从高到低）                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 命令行参数                                              │
│     java -jar app.jar --server.port=9090                   │
│                                                             │
│  2. 操作系统环境变量                                        │
│     SERVER_PORT=9090 java -jar app.jar                      │
│                                                             │
│  3. JNDI属性                                                │
│                                                             │
│  4. 外部配置文件                                            │
│     ./config/application.yml                                │
│     ./application.yml                                       │
│                                                             │
│  5. 内部配置文件                                            │
│     classpath:/config/application.yml                       │
│     classpath:/application.yml                             │
│                                                             │
│  6. @PropertySource注解                                     │
│     @PropertySource("classpath:custom.properties")         │
│                                                             │
│  7. 默认值                                                  │
│     @Value("${app.name:default}")                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 6.2 配置属性源

```java
@Configuration
public class AppConfig implements EnvironmentAware {
    
    private Environment environment;
    
    @Override
    public void setEnvironment(Environment environment) {
        this.environment = environment;
    }
    
    // 获取配置值
    public String getConfigValue(String key) {
        // 从所有属性源中查找，按优先级返回第一个匹配的值
        return environment.getProperty(key);
    }
    
    public String getConfigValue(String key, String defaultValue) {
        return environment.getProperty(key, defaultValue);
    }
    
    public <T> T getConfigValue(String key, Class<T> type) {
        return environment.getProperty(key, type);
    }
}
```

### 6.3 自定义属性源

```java
// 添加自定义属性源
@Component
public class CustomPropertySourceLoader implements EnvironmentPostProcessor {
    
    @Override
    public void postProcessEnvironment(
            ConfigurableEnvironment environment,
            SpringApplication application) {
        
        // 创建自定义属性源
        Map<String, Object> properties = new HashMap<>();
        properties.put("custom.property1", "value1");
        properties.put("custom.property2", "value2");
        
        PropertySource<?> customSource = new MapPropertySource(
            "customProperties", properties);
        
        // 添加到属性源列表（优先级最高）
        environment.getPropertySources().addFirst(customSource);
    }
}

// 注册到META-INF/spring.factories
# org.springframework.boot.env.EnvironmentPostProcessor=\
#   com.example.CustomPropertySourceLoader
```

## 七、敏感信息处理

### 7.1 Jasypt加密

```xml
<dependency>
    <groupId>com.github.ulisesbocchio</groupId>
    <artifactId>jasypt-spring-boot-starter</artifactId>
    <version>3.0.5</version>
</dependency>
```

```yaml
# application.yml
jasypt:
  encryptor:
    password: ${JASYPT_PASSWORD:secret-key}

spring:
  datasource:
    password: ENC(加密后的密码)
```

```java
// 加密工具
public class EncryptUtil {
    
    public static void main(String[] args) {
        StandardPBEStringEncryptor encryptor = new StandardPBEStringEncryptor();
        encryptor.setPassword("secret-key");
        
        // 加密
        String encrypted = encryptor.encrypt("my-db-password");
        System.out.println("加密结果：" + encrypted);
        
        // 解密
        String decrypted = encryptor.decrypt(encrypted);
        System.out.println("解密结果：" + decrypted);
    }
}
```

## 八、小结

SpringBoot的配置文件与环境管理为应用提供了灵活的配置机制：

1. **文件格式**：支持Properties和YAML两种格式
2. **多环境配置**：通过Profile实现dev/test/prod环境切换
3. **属性绑定**：@Value和@ConfigurationProperties两种方式
4. **加载优先级**：命令行 > 环境变量 > 外部文件 > 内部文件
5. **敏感信息**：支持加密、环境变量、配置中心等多种方式

最佳实践：
- 使用YAML格式（更清晰易读）
- 合理划分多环境配置
- 使用@ConfigurationProperties进行类型安全绑定
- 敏感信息使用加密或环境变量
- 生产配置使用外部化配置
