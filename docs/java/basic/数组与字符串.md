# Java 数组与字符串

数组和字符串是 Java 中最常用的数据结构。本文将深入讲解它们的特性、操作方法以及底层原理。

## 数组

### 数组基础

数组是相同类型元素的有序集合，在内存中连续存储。

```java
// 声明数组
int[] numbers;           // 推荐写法
int numbers2[];          // 兼容 C 风格（不推荐）

// 初始化数组
numbers = new int[5];    // 创建长度为 5 的数组
int[] values = {1, 2, 3, 4, 5};  // 静态初始化
int[] filled = new int[]{10, 20, 30};  // 匿名数组初始化

// 访问数组元素
System.out.println(values[0]);  // 1
System.out.println(values[4]);  // 5

// 修改数组元素
values[0] = 100;

// 获取数组长度
System.out.println(values.length);  // 5
```

### 数组的内存模型

```
┌─────────────────────────────────────────────┐
│                  堆内存                       │
│  ┌─────────────────────────────────────┐    │
│  │  int[] 数组对象                       │    │
│  │  ┌─────┬─────┬─────┬─────┬─────┐   │    │
│  │  │  1  │  2  │  3  │  4  │  5  │   │    │
│  │  └─────┴─────┴─────┴─────┴─────┘   │    │
│  │  地址: 0x1000                        │    │
│  └─────────────────────────────────────┘    │
└─────────────────────────────────────────────┘
        ↑
栈帧中的引用 (reference)
```

**关键特性**：
- 数组是引用类型，存储在堆内存中
- 数组变量存储的是引用（地址）
- 数组元素在内存中连续存储
- 数组长度在创建后不可改变

### 数组遍历

```java
int[] arr = {10, 20, 30, 40, 50};

// 方式一：for 循环
for (int i = 0; i < arr.length; i++) {
    System.out.printf("arr[%d] = %d%n", i, arr[i]);
}

// 方式二：增强 for 循环（for-each）
for (int value : arr) {
    System.out.println(value);
}

// 方式三：使用 Arrays 工具类
import java.util.Arrays;
System.out.println(Arrays.toString(arr));
// 输出: [10, 20, 30, 40, 50]

// 方式四：Java 8 Stream
Arrays.stream(arr).forEach(System.out::println);
```

### 多维数组

```java
// 二维数组
int[][] matrix = new int[3][4];  // 3行4列

// 初始化
int[][] scores = {
    {85, 92, 78},
    {90, 88, 95},
    {76, 82, 89}
};

// 不规则二维数组
int[][] jagged = new int[3][];
jagged[0] = new int[]{1, 2};
jagged[1] = new int[]{3, 4, 5};
jagged[2] = new int[]{6};

// 遍历二维数组
for (int i = 0; i < scores.length; i++) {
    for (int j = 0; j < scores[i].length; j++) {
        System.out.printf("%d ", scores[i][j]);
    }
    System.out.println();
}
```

### Arrays 工具类

`java.util.Arrays` 提供了丰富的数组操作方法：

```java
import java.util.Arrays;

int[] arr = {5, 3, 8, 1, 9, 2, 7, 4, 6};

// 排序
Arrays.sort(arr);
System.out.println(Arrays.toString(arr));
// [1, 2, 3, 4, 5, 6, 7, 8, 9]

// 二分查找（必须先排序）
int index = Arrays.binarySearch(arr, 7);  // 返回 6

// 填充数组
int[] filled = new int[5];
Arrays.fill(filled, 42);
// [42, 42, 42, 42, 42]

// 数组复制
int[] copy = Arrays.copyOf(arr, arr.length);
int[] rangeCopy = Arrays.copyOfRange(arr, 2, 5);

// 数组比较
boolean equal = Arrays.equals(arr, copy);

// 转为 List
List<Integer> list = Arrays.asList(1, 2, 3, 4, 5);

// Java 8: parallelSort（并行排序，大数据量更快）
Arrays.parallelSort(arr);
```

## 字符串

### String 类基础

```java
// 创建字符串
String s1 = "Hello";              // 字符串常量池
String s2 = new String("Hello");  // 堆内存新对象
String s3 = new String(new char[]{'H', 'i'});

// 字符串比较
System.out.println(s1 == s2);      // false（引用比较）
System.out.println(s1.equals(s2)); // true（内容比较）

// 字符串常量池
String a = "Java";
String b = "Java";
System.out.println(a == b);  // true（同一对象）
```

### 字符串常量池

```
┌─────────────────────────────────────────┐
│           方法区 / 元空间                │
│  ┌─────────────────────────────────┐   │
│  │        字符串常量池               │   │
│  │  ┌─────────────┐                │   │
│  │  │ "Hello"     │ ← s1, s3 指向  │   │
│  │  └─────────────┘                │   │
│  │  ┌─────────────┐                │   │
│  │  │ "Java"      │ ← a, b 指向    │   │
│  │  └─────────────┘                │   │
│  └─────────────────────────────────┘   │
└─────────────────────────────────────────┘
```

**字符串创建过程**：
1. `String s = "Hello"`：检查常量池，存在则直接引用，不存在则创建
2. `String s = new String("Hello")`：在堆内存创建新对象，即使常量池已有

### 字符串常用方法

```java
String str = "Hello, Java World!";

// 获取信息
str.length();                    // 18（长度）
str.charAt(0);                   // 'H'（获取字符）
str.indexOf('J');                // 7（查找位置）
str.indexOf("Java");             // 7
str.lastIndexOf('o');            // 16

// 字符串判断
str.startsWith("Hello");         // true
str.endsWith("World!");          // true
str.contains("Java");            // true
str.isEmpty();                   // false

// 字符串转换
str.toUpperCase();               // "HELLO, JAVA WORLD!"
str.toLowerCase();               // "hello, java world!"
str.trim();                      // 去除首尾空格

// 字符串替换
str.replace("Java", "Python");   // "Hello, Python World!"
str.replaceAll("\\s", "-");      // "Hello,-Java-World!"

// 字符串分割
String[] parts = str.split(", ");  // ["Hello", "Java World!"]

// 字符串截取
str.substring(7, 11);            // "Java"（[begin, end)）

// 字符串比较
str.equals("Hello, Java World!");      // true
str.equalsIgnoreCase("hello...");     // true
str.compareTo("Hello, Python!");      // 负数（按字典序）
```

### 字符串不可变性

String 对象创建后不可改变，任何修改操作都会创建新对象。

```java
String original = "Hello";
String modified = original.concat(" World");
// original 仍然是 "Hello"
// modified 是新对象 "Hello World"

// 演示不可变性
String s = "Java";
s = s.concat(" Script");  // s 现在指向新对象
// 原 "Java" 对象仍在常量池中
```

**不可变的原因**：
1. **字符串常量池**：共享对象，节省内存
2. **安全性**：防止被意外修改
3. **线程安全**：不可变对象天然线程安全
4. **性能优化**：可以缓存 hash 值

### 字符串拼接

```java
// 方式一：+ 运算符
String result = "Hello" + " " + "Java";

// 方式二：concat 方法
String result2 = "Hello".concat(" ").concat("Java");

// 方式三：StringBuilder（推荐，大量拼接时）
StringBuilder sb = new StringBuilder();
sb.append("Hello")
  .append(" ")
  .append("Java")
  .append("!");
String result3 = sb.toString();

// 性能比较
// + 运算符：每次拼接创建新对象，O(n²)
// StringBuilder：内部缓冲区，O(n)
```

### StringBuilder 和 StringBuffer

```java
// StringBuilder：非线程安全，性能高（推荐）
StringBuilder sb = new StringBuilder();

// StringBuffer：线程安全，性能略低
StringBuffer buffer = new StringBuffer();

// 常用方法
StringBuilder sb = new StringBuilder("Hello");
sb.append(" World");           // 追加
sb.insert(5, ",");             // 插入
sb.delete(5, 6);              // 删除
sb.reverse();                  // 反转
sb.replace(0, 5, "Hi");        // 替换
sb.setCharAt(0, 'h');          // 设置字符
String result = sb.toString(); // 转为 String

// 设置初始容量（可选优化）
StringBuilder optimized = new StringBuilder(1024);
```

### 字符串格式化

```java
// String.format()
String message = String.format("姓名: %s, 年龄: %d, 成绩: %.1f",
                               "张三", 25, 95.5);

// 常用格式符
// %s - 字符串
// %d - 十进制整数
// %f - 浮点数
// %c - 字符
// %t - 日期时间

// 高级格式化
System.out.printf("%-10s %5d %8.2f%n", "Java", 100, 3.14);
// 左对齐10位 右对齐5位 保留2位小数

// 日期格式化
import java.time.LocalDateTime;
LocalDateTime now = LocalDateTime.now();
String formatted = String.format("%tY-%tm-%td %tH:%tM", now, now, now, now, now);
```

## 字符串与数字互转

```java
// 字符串 → 数字
int num1 = Integer.parseInt("123");
double num2 = Double.parseDouble("3.14");
long num3 = Long.parseLong("1000000");

// 数字 → 字符串
String s1 = String.valueOf(123);
String s2 = Integer.toString(456);
String s3 = 789 + "";  // 隐式转换

// 进制转换
String binary = Integer.toBinaryString(10);    // "1010"
String hex = Integer.toHexString(255);          // "ff"
String octal = Integer.toOctalString(8);        // "10"
int fromBinary = Integer.parseInt("1010", 2);   // 10
```

## 实用技巧

### 字符串判空

```java
// 推荐写法（常量在前）
if ("".equals(str)) {
    // 空字符串处理
}

// 或使用工具方法
if (str == null || str.isEmpty()) {
    // null 或空字符串
}

// Apache Commons
// StringUtils.isBlank(str)  // null、空串、纯空白
// StringUtils.isNotBlank(str)
```

### 高效字符串拼接

```java
// 循环中拼接字符串，务必使用 StringBuilder
StringBuilder result = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    result.append("item").append(i).append(",");
}
String finalResult = result.toString();

// 使用 String.join（Java 8+）
List<String> list = Arrays.asList("A", "B", "C");
String joined = String.join(", ", list);  // "A, B, C"

// 使用 Stream（Java 8+）
String joined2 = list.stream().collect(Collectors.joining(", "));
```

### 字符串池优化

```java
// intern() 方法：将字符串放入常量池
String s = new String("Hello").intern();
// 如果常量池已有 "Hello"，返回其引用
// 否则将新字符串加入常量池

// 应用场景：大量重复字符串时节省内存
Set<String> uniqueStrings = new HashSet<>();
for (String s : largeList) {
    uniqueStrings.add(s.intern());
}
```
