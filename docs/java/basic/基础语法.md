# Java 基础语法

Java 基础语法是构建 Java 程序的基石。本文将详细讲解 Java 的基本语法规则、数据类型、运算符、控制流程等核心概念。

## 基本语法规则

### Java 程序结构

```java
package com.example;  // 包声明（可选）

/**
 * 文档注释
 * @author YourName
 */
public class BasicSyntax {  // 类名，与文件名一致
    
    // 成员变量
    private String name;
    
    // 构造方法
    public BasicSyntax(String name) {
        this.name = name;
    }
    
    // 成员方法
    public void display() {
        // 方法体
        System.out.println("Hello, " + name);
    }
    
    // 主方法（程序入口）
    public static void main(String[] args) {
        BasicSyntax example = new BasicSyntax("Java");
        example.display();
    }
}
```

### 语法要点

- **大小写敏感**：Java 是大小写敏感的语言，`Hello` 和 `hello` 是不同的标识符
- **类名大驼峰**：类名每个单词首字母大写，如 `HelloWorld`
- **方法名小驼峰**：方法名第一个单词小写，后续单词首字母大写，如 `getUserName`
- **花括号**：代码块使用 `{}` 包围
- **分号结尾**：每条语句以 `;` 结尾
- **注释**：支持单行 `//`、多行 `/* */` 和文档 `/** */`

## 数据类型

### 基本数据类型

Java 有 8 种基本数据类型：

| 类型 | 大小 | 范围 | 默认值 | 示例 |
|------|------|------|--------|------|
| `byte` | 1字节 | -128 ~ 127 | 0 | `byte b = 10;` |
| `short` | 2字节 | -32768 ~ 32767 | 0 | `short s = 1000;` |
| `int` | 4字节 | -2³¹ ~ 2³¹-1 | 0 | `int i = 100000;` |
| `long` | 8字节 | -2⁶³ ~ 2⁶³-1 | 0L | `long l = 1000000L;` |
| `float` | 4字节 | IEEE 754 | 0.0f | `float f = 3.14f;` |
| `double` | 8字节 | IEEE 754 | 0.0d | `double d = 3.14159;` |
| `char` | 2字节 | Unicode 0~65535 | '\u0000' | `char c = 'A';` |
| `boolean` | 1位 | true/false | false | `boolean flag = true;` |

### 引用数据类型

```java
// 字符串
String str = "Hello";

// 数组
int[] numbers = {1, 2, 3};

// 对象
Object obj = new Object();

// 包装类
Integer integer = 42;
Double doubleObj = 3.14;
Boolean boolObj = true;
```

### 类型转换

```java
// 自动类型转换（小类型 → 大类型）
int i = 10;
long l = i;        // int → long
float f = i;       // int → float
double d = f;      // float → double

// 强制类型转换（大类型 → 小类型）
double d2 = 3.14;
int i2 = (int) d2;  // 结果: 3
long l2 = (long) d2; // 结果: 3L

// 注意：可能丢失精度或溢出
int large = 130;
byte b = (byte) large;  // 结果: -126（溢出）
```

## 变量与常量

### 变量声明

```java
// 声明并初始化
int age = 25;
String name = "张三";

// 先声明后初始化
double salary;
salary = 10000.0;

// 多个同类型变量
int x = 10, y = 20, z = 30;
```

### 变量作用域

```java
public class Scope {
    private int classVar = 100;  // 类变量（成员变量）
    
    public void method() {
        int methodVar = 50;  // 方法变量
        
        if (true) {
            int blockVar = 25;  // 块变量
            System.out.println(blockVar);
        }
        // System.out.println(blockVar);  // 错误！blockVar 已超出作用域
        
        System.out.println(methodVar);
    }
}
```

### 常量

```java
public static final int MAX_RETRY_COUNT = 3;
```

## 运算符

### 算术运算符

```java
int a = 10, b = 3;

System.out.println(a + b);   // 13（加）
System.out.println(a - b);   // 7（减）
System.out.println(a * b);   // 30（乘）
System.out.println(a / b);   // 3（整除）
System.out.println(a % b);   // 1（取余）

// 自增自减
int c = 5;
System.out.println(c++);  // 5（先使用，后自增）
System.out.println(c);    // 6
System.out.println(++c);  // 7（先自增，后使用）
System.out.println(c--);  // 7
```

### 赋值运算符

```java
int x = 10;

x += 5;   // x = x + 5 = 15
x -= 3;   // x = x - 3 = 12
x *= 2;   // x = x * 2 = 24
x /= 4;   // x = x / 4 = 6
x %= 3;   // x = x % 3 = 0
```

### 比较运算符

```java
int a = 10, b = 20;

System.out.println(a == b);   // false
System.out.println(a != b);   // true
System.out.println(a > b);    // false
System.out.println(a < b);    // true
System.out.println(a >= b);   // false
System.out.println(a <= b);   // true
```

### 逻辑运算符

```java
boolean x = true, y = false;

System.out.println(x && y);  // false（短路与）
System.out.println(x || y);  // true（短路或）
System.out.println(!x);      // false（非）

// 短路行为演示
int i = 0;
boolean result = x && (++i > 0);  // y 为 false 时，(++i > 0) 不会执行
System.out.println(i);  // 0（未执行自增）
```

### 位运算符

```java
int a = 0b1010;  // 10
int b = 0b1100;  // 12

System.out.println(a & b);   // 8  (0b1000) 按位与
System.out.println(a | b);   // 14 (0b1110) 按位或
System.out.println(a ^ b);   // 6  (0b0110) 按位异或
System.out.println(~a);      // -11 (按位取反)

// 移位运算
System.out.println(a << 2);  // 40 (左移2位)
System.out.println(a >> 1);  // 5  (右移1位)
System.out.println(a >>> 1); // 5  (无符号右移)
```

## 控制流程

### if-else 语句

```java
int score = 85;

// 简单 if
if (score >= 60) {
    System.out.println("及格");
}

// if-else
if (score >= 90) {
    System.out.println("优秀");
} else {
    System.out.println("其他");
}

// if-else if-else
if (score >= 90) {
    System.out.println("A级");
} else if (score >= 80) {
    System.out.println("B级");
} else if (score >= 60) {
    System.out.println("C级");
} else {
    System.out.println("D级");
}

// 三元运算符
String grade = score >= 60 ? "及格" : "不及格";
```

### switch 语句

```java
int day = 3;

switch (day) {
    case 1:
        System.out.println("星期一");
        break;
    case 2:
        System.out.println("星期二");
        break;
    case 3:
        System.out.println("星期三");
        break;
    default:
        System.out.println("其他");
}

// Java 14+ 新语法（switch 表达式）
String dayName = switch (day) {
    case 1 -> "星期一";
    case 2 -> "星期二";
    case 3 -> "星期三";
    default -> "其他";
};
```

### for 循环

```java
// 传统 for 循环
for (int i = 0; i < 5; i++) {
    System.out.println("i = " + i);
}

// 增强 for 循环（for-each）
int[] numbers = {1, 2, 3, 4, 5};
for (int num : numbers) {
    System.out.println(num);
}

// for 循环实现九九乘法表
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.printf("%d × %d = %d\t", j, i, i * j);
    }
    System.out.println();
}
```

### while 循环

```java
// while 循环
int count = 0;
while (count < 5) {
    System.out.println(count);
    count++;
}

// do-while 循环（至少执行一次）
int num = 10;
do {
    System.out.println(num);
    num++;
} while (num < 5);  // 条件为 false，但仍执行一次

// 无限循环（用于服务器、游戏循环等）
while (true) {
    // 业务逻辑
    if (shouldStop()) {
        break;
    }
}
```

### break 和 continue

```java
// break：跳出整个循环
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;  // 跳出循环
    }
    System.out.println(i);
}

// continue：跳过当前迭代
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) {
        continue;  // 跳过偶数
    }
    System.out.println(i);  // 只输出奇数
}

// 带标签的 break/continue（用于嵌套循环）
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (i == 1 && j == 1) {
            break outer;  // 跳出外层循环
        }
        System.out.printf("(%d, %d) ", i, j);
    }
}
```

## 输入与输出

### 控制台输出

```java
// println：输出后换行
System.out.println("Hello");

// print：输出后不换行
System.out.print("Hello ");
System.out.print("World");

// printf：格式化输出
System.out.printf("姓名: %s, 年龄: %d%n", "张三", 25);
System.out.printf("金额: %.2f%n", 1234.5678);

// 常用格式符
// %s - 字符串
// %d - 整数
// %f - 浮点数
// %c - 字符
// %b - 布尔值
// %n - 换行
```

### 控制台输入

```java
import java.util.Scanner;

public class InputDemo {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("请输入姓名: ");
        String name = scanner.nextLine();
        
        System.out.print("请输入年龄: ");
        int age = scanner.nextInt();
        
        System.out.print("请输入身高(米): ");
        double height = scanner.nextDouble();
        
        System.out.printf("姓名: %s, 年龄: %d, 身高: %.2f米%n", 
                         name, age, height);
        
        scanner.close();
    }
}
```

## 编码规范

### 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 包名 | 全小写，域名反转 | `com.example.project` |
| 类名 | 大驼峰 | `HelloWorld` |
| 方法名 | 小驼峰 | `getUserName` |
| 变量名 | 小驼峰 | `userName` |
| 常量 | 全大写，下划线 | `MAX_SIZE` |
| 接口 | 大驼峰 | `Runnable` |
| 枚举 | 大驼峰 | `Color` |

### 代码格式

- 缩进：4 个空格（不使用 Tab）
- 行宽：不超过 120 个字符
- 空行：逻辑之间空一行
- 花括号：同行放置（K&R 风格）

```java
// 推荐写法
if (condition) {
    // 代码
} else {
    // 代码
}

// 不推荐写法
if (condition)
{
    // 代码
}
```
