# Java 环境搭建

[官方文档](https://docs.oracle.com/en/java/)

Java 是由 Sun Microsystems 公司（现 Oracle 公司）开发的一种面向对象的编程语言。它以"一次编写，到处运行"（Write Once, Run Anywhere）的特性而闻名，广泛应用于企业级开发、Android 开发、大数据处理等领域。

## Java 简介

### Java 的特点

- **简单性**：Java 移除了指针、多继承等复杂特性，语法清晰
- **面向对象**：封装、继承、多态，符合人类思维习惯
- **平台无关性**：通过 JVM 实现跨平台运行
- **安全性**：字节码校验、沙箱机制保证安全
- **多线程**：内置多线程支持，适合并发编程
- **自动垃圾回收**：JVM 自动管理内存，减少内存泄漏

### Java 版本选择

目前主要使用的 Java 版本：

| 版本 | 特点 | 适用场景 |
|------|------|----------|
| Java 8 | LTS 版本，生态最成熟 | 企业级项目、遗留系统 |
| Java 11 | LTS 版本，性能提升 | 新项目、微服务 |
| Java 17 | LTS 版本，虚拟线程预览 | 云原生、高并发 |
| Java 21 | LTS 版本，正式虚拟线程 | 现代应用开发 |

> 💡 **建议**：新项目推荐使用 Java 17 或 Java 21，它们是长期支持版本。

## 安装 JDK

JDK（Java Development Kit）是 Java 的开发工具包，包含 JRE、编译器、调试器等工具。

### Windows 系统

1. **下载 JDK**
   - 访问 [Oracle 官网](https://www.oracle.com/java/technologies/downloads/) 或 [Adoptium](https://adoptium.net/)
   - 下载 JDK 17 或 JDK 21 的 Windows 版本（.msi 安装包）

2. **运行安装程序**
   - 双击下载的 `.msi` 文件
   - 选择安装路径（建议：`C:\Java\jdk-17`）
   - 点击"下一步"完成安装

3. **配置环境变量**
   ```powershell
   # 设置 JAVA_HOME
   [Environment]::SetEnvironmentVariable("JAVA_HOME", "C:\Java\jdk-17", "Machine")
   
   # 添加到 PATH
   $currentPath = [Environment]::GetEnvironmentVariable("Path", "Machine")
   [Environment]::SetEnvironmentVariable("Path", "$currentPath;C:\Java\jdk-17\bin", "Machine")
   ```

4. **验证安装**
   ```bash
   java --version
   javac --version
   ```
   如果显示版本号，说明安装成功。

### macOS 系统

1. **使用 Homebrew 安装**（推荐）
   ```bash
   # 安装 JDK 17
   brew install openjdk@17
   
   # 或者安装 JDK 21
   brew install openjdk@21
   ```

2. **配置环境变量**
   ```bash
   # 添加到 ~/.zshrc 或 ~/.bash_profile
   export JAVA_HOME=$(/usr/libexec/java_home -v 17)
   export PATH=$JAVA_HOME/bin:$PATH
   ```

3. **验证安装**
   ```bash
   java --version
   ```

### Linux 系统

1. **Ubuntu/Debian**
   ```bash
   # 安装 OpenJDK
   sudo apt update
   sudo apt install openjdk-17-jdk
   
   # 配置 JAVA_HOME
   echo 'export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64' >> ~/.bashrc
   echo 'export PATH=$JAVA_HOME/bin:$PATH' >> ~/.bashrc
   source ~/.bashrc
   ```

2. **CentOS/RHEL**
   ```bash
   sudo yum install java-17-openjdk-devel
   
   # 或使用 dnf
   sudo dnf install java-17-openjdk-devel
   ```

## 第一个 Java 程序

### 创建项目

1. 打开 IDEA
2. 点击 "New Project"
3. 选择 "Java"，设置项目名称和路径
4. 选择 JDK 版本
5. 点击 "Create"

### 编写 Hello World

```java
// HelloWorld.java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
        System.out.println("欢迎来到 Java 世界！");
        
        // 变量演示
        String name = "Java";
        int version = 17;
        System.out.printf("当前版本: %s %d%n", name, version);
    }
}
```

### 运行程序

**方式一：IDE 中运行**
- 右键点击 `HelloWorld.java` → Run 'HelloWorld.main()'
- 或点击类名旁边的绿色三角形

**方式二：命令行运行**
```bash
# 编译
javac HelloWorld.java

# 运行
java HelloWorld
```

### 输出结果
```
Hello, Java!
欢迎来到 Java 世界！
当前版本: Java 17
```

## Maven 与 Gradle

Maven 和 Gradle 是 Java 的构建工具，用于管理依赖、编译、打包等。

### Maven

**安装 Maven**
```bash
# Windows：下载解压后配置环境变量
# macOS
brew install maven

# Linux
sudo apt install maven
```

**创建 Maven 项目**
```bash
mvn archetype:generate -DgroupId=com.example -DartifactId=my-app -Dversion=1.0.0
```

**基本命令**
```bash
mvn compile      # 编译
mvn test         # 测试
mvn package      # 打包
mvn clean        # 清理
mvn install      # 安装到本地仓库
```

**pom.xml 示例**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0">
    <modelVersion>4.0.0</modelVersion>
    <groupId>com.example</groupId>
    <artifactId>my-app</artifactId>
    <version>1.0.0</version>
    
    <properties>
        <maven.compiler.source>17</maven.compiler.source>
        <maven.compiler.target>17</maven.compiler.target>
    </properties>
    
    <dependencies>
        <!-- 添加依赖 -->
        <dependency>
            <groupId>junit</groupId>
            <artifactId>junit</artifactId>
            <version>4.13.2</version>
            <scope>test</scope>
        </dependency>
    </dependencies>
</project>
```

### Gradle

**安装 Gradle**
```bash
# macOS
brew install gradle

# 使用 SDKMAN
curl -s "https://get.sdkman.io" | bash
sdk install gradle
```

**创建 Gradle 项目**
```bash
gradle init --type java-application
```

**build.gradle 示例**
```groovy
plugins {
    id 'java'
}

java {
    sourceCompatibility = JavaVersion.VERSION_17
    targetCompatibility = JavaVersion.VERSION_17
}

repositories {
    mavenCentral()
}

dependencies {
    testImplementation 'junit:junit:4.13.2'
}
```

## 常见问题

### 1. JAVA_HOME 设置不正确

**问题**：`JAVA_HOME` 指向 JRE 而非 JDK，或路径包含空格。

**解决**：确保 `JAVA_HOME` 指向 JDK 根目录（包含 `bin`、`lib` 的目录），路径尽量不要包含空格。

### 2. 版本不匹配

**问题**：项目使用 Java 8，但 JDK 是 17。

**解决**：在 IDE 中配置正确的 JDK 版本：
- File → Project Structure → Project SDK
- 或在 `pom.xml` 中指定 `maven.compiler.source`

### 3. 依赖下载失败

**问题**：Maven/Gradle 无法下载依赖。

**解决**：
- 检查网络连接
- 配置国内镜像源（如阿里云镜像）
- 清理本地仓库缓存

### 4. 编码问题

**问题**：中文乱码。

**解决**：
- 设置文件编码为 UTF-8
- Maven 配置：`<project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>`
