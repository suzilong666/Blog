# Java 并发编程

并发编程是 Java 的核心能力之一。本文将从基础到深入，讲解线程、同步、并发工具以及并发编程的最佳实践。

## 并发编程概述

### 什么是并发

并发是指在同一时间段内同时处理多个任务。Java 提供了丰富的并发工具来支持多线程编程。

```
┌─────────────────────────────────────────────────────────┐
│                      并发 vs 并行                         │
│                                                           │
│  并发：交替执行（宏观上同时，微观上交替）                    │
│  ┌─────────┬─────────┬─────────┬─────────┐              │
│  │ 任务 A  │ 任务 B  │ 任务 A  │ 任务 B  │              │
│  └─────────┴─────────┴─────────┴─────────┘              │
│  时间 →                                                   │
│                                                           │
│  并行：真正同时执行（多核 CPU）                              │
│  ┌─────────────────┐  ┌─────────────────┐               │
│  │    CPU 核心 1     │  │    CPU 核心 2     │               │
│  │  ┌─────────────┐│  │  ┌─────────────┐│               │
│  │  │   任务 A    ││  │  │   任务 B    ││               │
│  │  └─────────────┘│  │  └─────────────┘│               │
│  └─────────────────┘  └─────────────────┘               │
└─────────────────────────────────────────────────────────┘
```

### 为什么需要并发

- **提高资源利用率**：避免 CPU 空闲等待 IO
- **提高响应速度**：一个任务阻塞不影响其他任务
- **简化编程**：将复杂任务分解为可并行的子任务
- **高吞吐量**：多任务同时处理，提高系统吞吐

## 线程基础

### 创建线程的方式

```java
// 方式一：继承 Thread 类
public class MyThread extends Thread {
    @Override
    public void run() {
        for (int i = 0; i < 5; i++) {
            System.out.println(Thread.currentThread().getName() + ": " + i);
            try {
                Thread.sleep(1000);  // 休眠 1 秒
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
    
    public static void main(String[] args) {
        MyThread thread = new MyThread("MyThread-1");
        thread.start();  // 启动线程
    }
}

// 方式二：实现 Runnable 接口
public class MyRunnable implements Runnable {
    @Override
    public void run() {
        System.out.println("Thread: " + Thread.currentThread().getName());
    }
    
    public static void main(String[] args) {
        Thread thread = new Thread(new MyRunnable(), "MyRunnable-1");
        thread.start();
    }
}

// 方式三：使用 Lambda 表达式
public class LambdaThread {
    public static void main(String[] args) {
        new Thread(() -> {
            System.out.println("Lambda thread running");
        }, "Lambda-Thread").start();
    }
}

// 方式四：使用 Callable 和 Future（有返回值）
import java.util.concurrent.Callable;
import java.util.concurrent.FutureTask;

public class CallableThread implements Callable<String> {
    @Override
    public String call() throws Exception {
        return "Hello from Callable!";
    }
    
    public static void main(String[] args) throws Exception {
        CallableThread callable = new CallableThread();
        FutureTask<String> futureTask = new FutureTask<>(callable);
        new Thread(futureTask).start();
        
        String result = futureTask.get();  // 获取结果（阻塞）
        System.out.println("Result: " + result);
    }
}
```

```java
public class ThreadMethods {
    
    public static void main(String[] args) throws Exception {
        // 获取当前线程
        Thread mainThread = Thread.currentThread();

        System.out.println("线程名: " + mainThread.getName());

            System.out.println("Worker thread running...");
            try {
                Thread.sleep(2000);  // 休眠 2 秒
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        });
        
        worker.setName("Worker-1");
        worker.setPriority(Thread.MAX_PRIORITY);  // 设置优先级
        worker.setDaemon(true);  // 设置为守护线程
        
        worker.start();
        
        // 等待子线程结束
        worker.join();  // main 线程等待 worker 结束
        System.out.println("Worker thread finished");
        
        // 中断线程
        // worker.interrupt();
    }
}
```

## 同步与互斥

### synchronized 关键字

```java
// 同步方法
public class SynchronizedMethod {
    
    private int count = 0;
    
    // 实例锁
    public synchronized void increment() {
        count++;
    }
    
    public synchronized int getCount() {
        return count;
    }
    
    // 静态方法使用类锁
    private static int staticCount = 0;
    
    public static synchronized void staticIncrement() {
        staticCount++;
    }
}

// 同步代码块
public class SynchronizedBlock {
    
    private int count = 0;
    private final Object lock = new Object();
    
    public void increment() {
        synchronized (lock) {
            count++;
        }
    }
    
    // 使用 this 作为锁
    public void incrementWithThis() {
        synchronized (this) {
            count++;
        }
    }
    
    // 使用 Class 对象作为锁
    public static void staticIncrement() {
        synchronized (SynchronizedBlock.class) {
            // ...
        }
    }
}
```

### Lock 接口

```java
import java.util.concurrent.locks.Lock;
import java.util.concurrent.locks.ReentrantLock;

public class LockExample {
    
    private final Lock lock = new ReentrantLock();
    private int count = 0;
    
    public void increment() {
        lock.lock();
        try {
            count++;
        } finally {
            lock.unlock();  // 必须在 finally 中释放
        }
    }
    
    // 尝试获取锁
    public boolean tryIncrement() {
        if (lock.tryLock()) {
            try {
                count++;
                return true;
            } finally {
                lock.unlock();
            }
        }
        return false;  // 获取锁失败
    }
    
    // 可中断获取锁
    public void interruptibleIncrement() throws InterruptedException {
        lock.lockInterruptibly();
        try {
            count++;
        } finally {
            lock.unlock();
        }
    }
}
```

### ReadWriteLock

```java
import java.util.concurrent.locks.ReadWriteLock;
import java.util.concurrent.locks.ReentrantReadWriteLock;

public class ReadWriteLockExample {
    
    private final ReadWriteLock rwLock = new ReentrantReadWriteLock();
    private String data;
    
    // 读锁：允许多个读线程并发
    public String read() {
        rwLock.readLock().lock();
        try {
            return data;
        } finally {
            rwLock.readLock().unlock();
        }
    }
    
    // 写锁：独占，阻塞所有读写
    public void write(String newData) {
        rwLock.writeLock().lock();
        try {
            data = newData;
        } finally {
            rwLock.writeLock().unlock();
        }
    }
}
```

## volatile 关键字

### volatile 的作用

```java
public class VolatileExample {
    
    // 作用一：保证可见性
    private volatile boolean running = true;
    
    public void stop() {
        running = false;
    }
    
    public void run() {
        while (running) {
            // 循环执行
            // 没有 volatile 可能导致死循环
            // 因为线程可能从本地缓存读取 running
        }
    }
    
    // 作用二：禁止指令重排序
    private static volatile int value = 0;
    private static volatile boolean flag = false;
    
    // 双重检查锁单例模式
    public class Singleton {
        private static volatile Singleton instance;
        
        public static Singleton getInstance() {
            if (instance == null) {  // 第一次检查
                synchronized (Singleton.class) {
                    if (instance == null) {  // 第二次检查
                        instance = new Singleton();
                        // volatile 防止指令重排序
                        // 1. 分配内存
                        // 2. 初始化对象
                        // 3. 指向引用
                        // 没有 volatile 可能 3 在 2 之前执行
                    }
                }
            }
            return instance;
        }
    }
}
```

### volatile vs synchronized

| 特性 | volatile | synchronized |
|------|----------|--------------|
| 可见性 | ✅ 保证 | ✅ 保证 |
| 原子性 | ❌ 不保证 | ✅ 保证 |
| 有序性 | ✅ 禁止重排序 | ✅ 保证 |
| 粒度 | 变量 | 方法/代码块 |
| 阻塞 | ❌ 不会阻塞 | ✅ 可能阻塞 |
| 适用场景 | 状态标志 | 复合操作 |

## 并发工具类

### CountDownLatch

```java
import java.util.concurrent.CountDownLatch;

public class CountDownLatchExample {
    
    public static void main(String[] args) throws InterruptedException {
        int threadCount = 5;
        CountDownLatch latch = new CountDownLatch(threadCount);
        
        // 创建多个线程并发执行
        for (int i = 0; i < threadCount; i++) {
            final int taskId = i;
            new Thread(() -> {
                try {
                    System.out.println("Task " + taskId + " started");
                    Thread.sleep(1000 * taskId);  // 模拟不同耗时
                    System.out.println("Task " + taskId + " completed");
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                } finally {
                    latch.countDown();  // 减少计数
                }
            }).start();
        }
        
        // 等待所有任务完成
        latch.await();
        System.out.println("All tasks completed!");
    }
}
```

### CyclicBarrier

```java
import java.util.concurrent.CyclicBarrier;

public class CyclicBarrierExample {
    
    public static void main(String[] args) {
        int threadCount = 3;
        
        // 所有线程到达屏障后，一起继续执行
        CyclicBarrier barrier = new CyclicBarrier(threadCount, () -> {
            System.out.println("All threads reached barrier, continue together!");
        });
        
        for (int i = 0; i < threadCount; i++) {
            final int id = i;
            new Thread(() -> {
                try {
                    System.out.println("Thread " + id + " working...");
                    Thread.sleep(1000 * id);
                    System.out.println("Thread " + id + " reached barrier");
                    
                    barrier.await();  // 等待其他线程
                    
                    System.out.println("Thread " + id + " continuing...");
                } catch (Exception e) {
                    Thread.currentThread().interrupt();
                }
            }).start();
        }
    }
}
```

### Semaphore

```java
import java.util.concurrent.Semaphore;

public class SemaphoreExample {
    
    public static void main(String[] args) {
        // 限制同时访问资源的线程数
        Semaphore semaphore = new Semaphore(3);  // 最多 3 个线程
        
        for (int i = 0; i < 10; i++) {
            final int id = i;
            new Thread(() -> {
                try {
                    semaphore.acquire();  // 获取许可
                    System.out.println("Thread " + id + " acquired permit");
                    Thread.sleep(1000);
                    System.out.println("Thread " + id + " releasing permit");
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                } finally {
                    semaphore.release();  // 释放许可
                }
            }).start();
        }
    }
}
```

```java
public class ConcurrentHashMapExample {

        ConcurrentHashMap<String, Integer> map = new ConcurrentHashMap<>();
        
        // 原子操作
        map.put("key1", 1);

        map.search(1, (k, v) -> v > 50 ? k : null);
    }
}
```

## 线程池

### 为什么需要线程池

```java
// 问题：频繁创建和销毁线程
// - 资源消耗大
// - 性能低下
// - 缺乏管理

public class BadThreadPool {
    public void processTasks(List<Runnable> tasks) {
        for (Runnable task : tasks) {
            new Thread(task).start();  // 每个任务创建新线程
        }
    }
}

// 解决方案：使用线程池
public class GoodThreadPool {
    private final ExecutorService executor;
    
    public GoodThreadPool(int poolSize) {
        this.executor = Executors.newFixedThreadPool(poolSize);
    }
    
    public void processTasks(List<Runnable> tasks) {
        for (Runnable task : tasks) {
            executor.submit(task);  // 复用线程
        }
    }
    
    public void shutdown() {
        executor.shutdown();
    }
}
```

### 线程池核心类

```java
import java.util.concurrent.*;

public class ThreadPoolExample {
    
    // 方式一：使用 Executors 快捷工厂
    public void createPool() {
        // 固定大小线程池
        ExecutorService fixedPool = Executors.newFixedThreadPool(10);
        
        // 单线程线程池
        ExecutorService singlePool = Executors.newSingleThreadExecutor();
        
        // 缓存线程池
        ExecutorService cachedPool = Executors.newCachedThreadPool();
        
        // 定时线程池
        ScheduledExecutorService scheduledPool = Executors.newScheduledThreadPool(5);
    }
    
    // 方式二：自定义 ThreadPoolExecutor（推荐）
    public ThreadPoolExecutor createCustomPool() {
        return new ThreadPoolExecutor(
            2,                          // corePoolSize: 核心线程数
            10,                         // maximumPoolSize: 最大线程数
            60L,                        // keepAliveTime: 空闲线程存活时间
            TimeUnit.SECONDS,
            new LinkedBlockingQueue<>(100),  // workQueue: 任务队列
            new ThreadFactory() {       // threadFactory: 线程工厂
                private final AtomicInteger counter = new AtomicInteger(0);
                @Override
                public Thread newThread(Runnable r) {
                    Thread t = new Thread(r, "MyThread-" + counter.incrementAndGet());
                    t.setDaemon(false);
                    return t;
                }
            },
            new ThreadPoolExecutor.CallerRunsPolicy()  // rejectedExecutionHandler: 拒绝策略
        );
    }
    
    // 提交任务
    public void submitTasks(ExecutorService executor) {
        // 提交 Runnable
        executor.submit(() -> {
            System.out.println("Task running");
        });
        
        // 提交 Callable（有返回值）
        Future<String> future = executor.submit(() -> {
            return "Task result";
        });
        
        // 获取结果
        try {
            String result = future.get(5, TimeUnit.SECONDS);
            System.out.println("Result: " + result);
        } catch (TimeoutException e) {
            future.cancel(true);
        }
    }
    
    // 关闭线程池
    public void shutdownPool(ExecutorService executor) {
        executor.shutdown();  // 优雅关闭
        try {
            if (!executor.awaitTermination(60, TimeUnit.SECONDS)) {
                executor.shutdownNow();  // 强制关闭
            }
        } catch (InterruptedException e) {
            executor.shutdownNow();
        }
    }
}
```

## 并发编程最佳实践

### 避免的陷阱

```java
// 1. 不要使用 stop() 方法（已废弃）
public void stopThread() {
    Thread thread = new Thread(() -> {
        while (!Thread.currentThread().isInterrupted()) {
            // 工作循环
        }
    });
    thread.start();
    
    // 推荐使用 interrupt()
    thread.interrupt();
}

// 2. 不要使用 suspend()/resume()（已废弃）
// 可能导致死锁

// 3. 避免在同步块中调用外部方法
public class DeadlockRisk {
    private final Object lock1 = new Object();
    private final Object lock2 = new Object();
    
    // 错误：在持有锁时调用可能获取其他锁的方法
    public void method1() {
        synchronized (lock1) {
            // ...
            method2();  // 可能导致死锁
        }
    }
    
    public void method2() {
        synchronized (lock2) {
            // ...
        }
    }
}

// 4. 注意线程安全的集合使用
public class ThreadSafeCollection {
    // 使用并发集合
    private final List<String> list = Collections.synchronizedList(new ArrayList<>());
    
    // 或使用并发集合类
    private final Map<String, Integer> map = new ConcurrentHashMap<>();
    
    // 遍历同步集合时需要额外同步
    public void iterateSafely() {
        synchronized (list) {
            for (String item : list) {
                // 遍历
            }
        }
    }
}
```

### 线程安全的实现方式

```java
public class ThreadSafeStrategies {
    
    // 策略一：不可变对象
    public class ImmutablePoint {
        private final int x;
        private final int y;
        
        public ImmutablePoint(int x, int y) {
            this.x = x;
            this.y = y;
        }
        
        // 无修改方法，天然线程安全
        public int getX() { return x; }
        public int getY() { return y; }
    }
    
    // 策略二：线程封闭
    public class ThreadConfined {
        // 变量仅在单线程中使用
        private final ThreadLocal<String> threadLocal = new ThreadLocal<>();
        
        public void setValue(String value) {
            threadLocal.set(value);  // 每个线程有独立副本
        }
        
        public String getValue() {
            return threadLocal.get();
        }
    }
    
    // 策略三：同步机制
    public class SynchronizedCounter {
        private int count = 0;
        private final Lock lock = new ReentrantLock();
        
        public void increment() {
            lock.lock();
            try {
                count++;
            } finally {
                lock.unlock();
            }
        }
        
        public int getCount() {
            return count;  // volatile 或同步读取
        }
    }
    
    // 策略四：并发容器
    public class ConcurrentStore {
        private final Queue<String> queue = new ConcurrentLinkedQueue<>();
        private final Map<String, Integer> map = new ConcurrentHashMap<>();
        
        public void add(String item) {
            queue.offer(item);
        }
        
        public String poll() {
            return queue.poll();
        }
    }
}
```
