# Java 序列化

序列化是将对象转换为字节流的过程，反序列化则是将字节流恢复为对象。本文将详细讲解 Java 序列化机制、自定义序列化以及 JSON 序列化等内容。

## 序列化概述

### 什么是序列化

序列化是将对象状态转换为可存储或传输的格式的过程。反序列化则是将这种格式恢复为对象。

```
┌─────────────────────────────────────────────────────────┐
│                    序列化过程                             │
│                                                           │
│  ┌─────────┐   序列化    ┌─────────┐   存储/传输    ┌─────┐│
│  │  对象    │ ────────► │ 字节流   │ ──────────► │ 文件 ││
│  │         │            │         │              │ 网络 ││
│  └─────────┘            └─────────┘              └─────┘│
│       ▲                                                │  │
│       │               反序列化                          │  │
│       └─────────────────────────────────────────────────┘  │
│                                                           │
│  应用场景：                                               │
│  1. 对象持久化（保存到文件）                              │
│  2. 网络传输（RMI、分布式系统）                           │
│  3. 会话状态保存                                          │
│  4. 深度拷贝                                              │
└─────────────────────────────────────────────────────────┘
```

### Java 原生序列化

```java
import java.io.*;

// 实现 Serializable 接口
public class User implements Serializable {
    
    private static final long serialVersionUID = 1L;  // 版本号
    
    private String name;
    private int age;
    
    // 不参与序列化的字段
    private transient String password;
    private static String company = "Tech Corp";  // 静态字段不参与序列化
    
    public User(String name, int age, String password) {
        this.name = name;
        this.age = age;
        this.password = password;
    }
    
    // getter 和 setter
    public String getName() { return name; }
    public int getAge() { return age; }
    public String getPassword() { return password; }
    
    @Override
    public String toString() {
        return "User{name='" + name + "', age=" + age + "}";
    }
}

// 序列化示例
public class SerializationExample {
    
    public static void main(String[] args) {
        User user = new User("张三", 25, "secret123");
        
        // 序列化：对象 → 字节流
        try (ObjectOutputStream oos = new ObjectOutputStream(
                new FileOutputStream("user.ser"))) {
            oos.writeObject(user);
            System.out.println("序列化成功");
        } catch (IOException e) {
            e.printStackTrace();
        }
        
        // 反序列化：字节流 → 对象
        try (ObjectInputStream ois = new ObjectInputStream(
                new FileInputStream("user.ser"))) {
            User deserialized = (User) ois.readObject();
            System.out.println("反序列化成功: " + deserialized);
            // password 为 null（因为 transient）
            System.out.println("Password: " + deserialized.getPassword());
        } catch (IOException | ClassNotFoundException e) {
            e.printStackTrace();
        }
    }
}
```

## 自定义序列化

### 使用 writeObject/readObject

```java
import java.io.*;

public class CustomSerialization implements Serializable {
    
    private static final long serialVersionUID = 1L;
    
    private String data;
    private int value;
    
    public CustomSerialization(String data, int value) {
        this.data = data;
        this.value = value;
    }
    
    // 自定义序列化逻辑
    private void writeObject(ObjectOutputStream out) throws IOException {
        // 可以进行加密、压缩等处理
        out.writeUTF(data);
        out.writeInt(value);
    }
    
    // 自定义反序列化逻辑
    private void readObject(ObjectInputStream in) throws IOException {
        // 对应 writeObject 的读取逻辑
        this.data = in.readUTF();
        this.value = in.readInt();
    }
    
    // 其他可选方法
    private Object writeReplace() throws ObjectStreamException {
        // 序列化前替换对象
        return this;
    }
    
    private Object readResolve() throws ObjectStreamException {
        // 反序列化后替换对象
        return this;
    }
}
```

### Externalizable 接口

```java
import java.io.*;

// Externalizable 需要手动实现序列化逻辑
public class ExternalizableUser implements Externalizable {
    
    private String name;
    private int age;
    
    // 必须有无参构造器
    public ExternalizableUser() {}
    
    public ExternalizableUser(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    @Override
    public void writeExternal(ObjectOutput out) throws IOException {
        // 手动写入字段
        out.writeUTF(name);
        out.writeInt(age);
    }
    
    @Override
    public void readExternal(ObjectInput in) throws IOException {
        // 手动读取字段
        this.name = in.readUTF();
        this.age = in.readInt();
    }
    
    @Override
    public String toString() {
        return "ExternalizableUser{name='" + name + "', age=" + age + "}";
    }
}
```

## JSON 序列化

### Gson 库

```java
import com.google.gson.Gson;
import com.google.gson.GsonBuilder;
import com.google.gson.reflect.TypeToken;
import java.lang.reflect.Type;
import java.util.*;

public class GsonExample {
    
    public static void main(String[] args) {
        Gson gson = new Gson();
        
        // 对象 → JSON
        User user = new User("张三", 25);
        String json = gson.toJson(user);
        System.out.println("JSON: " + json);
        // {"name":"张三","age":25}
        
        // JSON → 对象
        User deserialized = gson.fromJson(json, User.class);
        
        // 集合序列化
        List<User> userList = Arrays.asList(
            new User("Alice", 25),
            new User("Bob", 30)
        );
        String listJson = gson.toJson(userList);
        
        // 反序列化集合
        Type listType = new TypeToken<List<User>>(){}.getType();
        List<User> deserializedList = gson.fromJson(listJson, listType);
        
        // 高级配置
        Gson prettyGson = new GsonBuilder()
            .setPrettyPrinting()           // 格式化输出
            .serializeNulls()              // 序列化 null 值
            .setDateFormat("yyyy-MM-dd")  // 日期格式
            .excludeFieldsWithoutExposeAnnotation()
            .create();
        
        String prettyJson = prettyGson.toJson(user);
    }
    
    static class User {
        String name;
        int age;
        
        User(String name, int age) {
            this.name = name;
            this.age = age;
        }
    }
}
```

### Jackson 库

```java
import com.fasterxml.jackson.core.*;
import com.fasterxml.jackson.databind.*;
import com.fasterxml.jackson.databind.json.*;
import com.fasterxml.jackson.datatype.jsr310.JavaTimeModule;
import java.time.LocalDate;
import java.util.*;

public class JacksonExample {
    
    public static void main(String[] args) throws Exception {
        ObjectMapper mapper = new ObjectMapper();
        
        // 对象 → JSON
        User user = new User("张三", 25);
        String json = mapper.writeValueAsString(user);
        
        // JSON → 对象
        User deserialized = mapper.readValue(json, User.class);
        
        // JSON → 树模型
        JsonNode root = mapper.readTree(json);
        String name = root.get("name").asText();
        int age = root.get("age").asInt();
        
        // 集合操作
        List<User> userList = Arrays.asList(
            new User("Alice", 25),
            new User("Bob", 30)
        );
        String listJson = mapper.writeValueAsString(userList);
        
        // 配置 ObjectMapper
        ObjectMapper configMapper = JsonMapper.builder()
            .enable(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES)
            .disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS)
            .addModule(new JavaTimeModule())
            .build();
        
        // 复杂对象
        Map<String, Object> complexObject = new HashMap<>();
        complexObject.put("name", "Test");
        complexObject.put("date", LocalDate.now());
        String complexJson = configMapper.writeValueAsString(complexObject);
    }
    
    static class User {
        String name;
        int age;
        
        User(String name, int age) {
            this.name = name;
            this.age = age;
        }
    }
}
```

### Fastjson2 库

```java
import com.alibaba.fastjson2.*;

public class FastjsonExample {

        User user = new User("张三", 25);
        
        // 对象 → JSON
        String json = JSON.toJSONString(user);
        
        // JSON → 对象
```

### 安全注意事项

```java
// 1. 避免反序列化不受信任的数据
// 不要从不可信来源反序列化对象

// 2. 使用白名单过滤
public class SafeDeserializer {
    
    private static final Set<String> ALLOWED_CLASSES = Set.of(
        "com.example.User",
        "com.example.Order"
    );
    
    public Object safeDeserialize(byte[] data) throws Exception {
        try (ObjectInputStream ois = new ObjectInputStream(new ByteArrayInputStream(data)) {
            @Override
            protected Class<?> resolveClass(ObjectStreamClass desc) 
                    throws IOException, ClassNotFoundException {
                if (!ALLOWED_CLASSES.contains(desc.getName())) {
                    throw new InvalidClassException("Unauthorized deserialization attempt", desc.getName());
                }
                return super.resolveClass(desc);
            }
        }) {
            return ois.readObject();
        }
    }
}

// 3. 使用 JSON 替代原生序列化
// JSON 序列化更安全，可读，跨语言
```

### 深度拷贝

```java
public class DeepCopyExample {
    
    // 方式一：序列化/反序列化
    @SuppressWarnings("unchecked")
    public static <T> T deepCopy(T obj) {
        try {
            ByteArrayOutputStream baos = new ByteArrayOutputStream();
            ObjectOutputStream oos = new ObjectOutputStream(baos);
            oos.writeObject(obj);
            oos.close();
            
            ByteArrayInputStream bais = new ByteArrayInputStream(baos.toByteArray());
            ObjectInputStream ois = new ObjectInputStream(bais);
            T copy = (T) ois.readObject();
            ois.close();
            
            return copy;
        } catch (Exception e) {
            throw new RuntimeException("Deep copy failed", e);
        }
    }
    
    // 方式二：JSON 序列化
    public static <T> T deepCopyJson(T obj, Class<T> clazz) {
        Gson gson = new Gson();
        return gson.fromJson(gson.toJson(obj), clazz);
    }
}
```
