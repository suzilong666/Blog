# Java 泛型

泛型（Generics）是 Java 5 引入的重要特性，用于在编译期提供类型安全。本文将详细讲解泛型的使用方法、类型擦除机制以及通配符的应用。

## 泛型概述

### 为什么需要泛型

在泛型出现之前，集合类只能存储 Object 类型，导致：
- **类型不安全**：运行时可能出现 ClassCastException
- **强制类型转换**：使用时需要手动转换类型
- **无法在编译期检查**：错误只能在运行时发现

```java
// 没有泛型的问题（Java 1.4 及以前）
List list = new ArrayList();
list.add("Hello");
list.add(123);  // 可以添加任何类型

// 强制类型转换，可能抛出异常
String s = (String) list.get(0);  // "Hello"
String s2 = (String) list.get(1); // ClassCastException!

// 使用泛型（Java 5+）
List<String> safeList = new ArrayList<>();
safeList.add("Hello");
// safeList.add(123);  // 编译错误！

// 无需类型转换
String s = safeList.get(0);  // 直接获得 String 类型
```

### 泛型的好处

1. **类型安全**：编译期检查类型
2. **代码复用**：一套代码处理多种类型
3. **可读性强**：明确表示集合的元素类型
4. **无需强转**：自动类型推断

## 泛型的使用

### 泛型类

```java
// 定义泛型类
public class Box<T> {
    private T value;
    
    public Box(T value) {
        this.value = value;
    }
    
    public T getValue() {
        return value;
    }
    
    public void setValue(T value) {
        this.value = value;
    }
    
    @Override
    public String toString() {
        return "Box{" + value + '}';
    }
}

// 使用泛型类
Box<String> stringBox = new Box<>("Hello");
Box<Integer> intBox = new Box<>(42);

String s = stringBox.getValue();  // String 类型
Integer i = intBox.getValue();   // Integer 类型
```

### 泛型接口

```java
// 定义泛型接口
public interface Repository<T, ID> {
    T findById(ID id);
    List<T> findAll();
    T save(T entity);
    void deleteById(ID id);
}

// 实现泛型接口
public class UserRepository implements Repository<User, Long> {
    private final Map<Long, User> storage = new ConcurrentHashMap<>();
    private long sequence = 1;
    
    @Override
    public User findById(Long id) {
        return storage.get(id);
    }
    
    @Override
    public List<User> findAll() {
        return new ArrayList<>(storage.values());
    }
    
    @Override
    public User save(User user) {
        Long id = user.getId() != null ? user.getId() : sequence++;
        user.setId(id);
        storage.put(id, user);
        return user;
    }
    
    @Override
    public void deleteById(Long id) {
        storage.remove(id);
    }
}
```

### 泛型方法

```java
public class GenericUtils {
    
    // 泛型方法：在返回类型前声明类型参数
    public static <T> T firstElement(List<T> list) {
        if (list == null || list.isEmpty()) {
            return null;
        }
        return list.get(0);
    }
    
    // 多个类型参数
    public static <K, V> Map<K, V> toMap(K key, V value) {
        Map<K, V> map = new HashMap<>();
        map.put(key, value);
        return map;
    }
    
    // 边界限定的泛型方法
    public static <T extends Number> double sum(List<T> numbers) {
        double total = 0;
        for (T num : numbers) {
            total += num.doubleValue();
        }
        return total;
    }
    
    // 通用数组转换
    @SafeVarargs
    public static <T> List<T> asList(T... elements) {
        return new ArrayList<>(Arrays.asList(elements));
    }
}

// 使用泛型方法
String first = GenericUtils.firstElement(Arrays.asList("A", "B", "C"));
Map<String, Integer> map = GenericUtils.toMap("count", 10);
double total = GenericUtils.sum(Arrays.asList(1, 2.5, 3));
```

## 类型参数的命名约定

| 字母 | 含义 | 示例 |
|------|------|------|
| E | Element（元素） | `List<E>`, `Set<E>` |
| T | Type（类型） | `Box<T>`, `Comparable<T>` |
| K | Key（键） | `Map<K, V>` |
| V | Value（值） | `Map<K, V>` |
| N | Number（数字） | `NumberSupplier<N>` |
| S | Second（第二个） | 任意第二类型 |

## 边界限定

### 上界限定 <T extends>

```java
// 限定类型参数必须是某个类或其子类
public class NumberBox<T extends Number> {
    private T value;
    
    public NumberBox(T value) {
        this.value = value;
    }
    
    // 可以调用 Number 的方法
    public double toDouble() {
        return value.doubleValue();
    }
}

// 使用
NumberBox<Integer> intBox = new NumberBox<>(42);
NumberBox<Double> doubleBox = new NumberBox<>(3.14);
// NumberBox<String>  // 编译错误！String 不是 Number 的子类
```

### 多边界限定

```java
// T 必须同时满足多个条件
public class Processor<T extends Number & Comparable<T>> {
    // T 必须是 Number 的子类，并且实现了 Comparable 接口
    
    public T process(T input) {
        // 可以调用 Number 的方法
        double val = input.doubleValue();
        
        // 可以调用 Comparable 的方法
        int comparison = input.compareTo(input);
        
        return input;
    }
}
```

### 下界限定 <? super>

```java
// 通配符的下界限定
public class BoundedWildcard {
    
    // 只接受 Integer 及其父类
    public void addNumber(List<? super Integer> list) {
        list.add(1);    // 可以添加 Integer
        list.add(42);   // 可以添加 Integer
        // list.add(3.14);  // 编译错误！Double 不是 Integer
    }
    
    // 使用场景：当需要向集合中添加元素时
    public static <T> void addAll(List<? super T> destination, List<? extends T> source) {
        destination.addAll(source);
    }
}
```

## 通配符

### 无界通配符 <?>

```java
// 表示未知类型，只读安全
public class UnboundedWildcard {
    
    // 可以接受任意类型的 List
    public void printList(List<?> list) {
        for (Object element : list) {
            System.out.println(element);
        }
        // 注意：不能添加元素（除了 null）
        // list.add("test");  // 编译错误
    }
    
    // 通配符捕获
    public <T> void listList(List<?> list) {
        // 需要通过泛型方法来处理
        System.out.println("List size: " + list.size());
    }
}
```

### 上界通配符 <? extends>

```java
// 表示某类型及其子类型，适合读取
public class UpperBoundedWildcard {
    
    // 只接受 Number 或其子类的 List
    public double sumList(List<? extends Number> list) {
        double total = 0;
        for (Number num : list) {
            total += num.doubleValue();
        }
        // 注意：不能添加元素
        // list.add(1);  // 编译错误！类型未知
        return total;
    }
    
    // 使用
    List<Integer> intList = Arrays.asList(1, 2, 3);
    List<Double> doubleList = Arrays.asList(1.5, 2.5, 3.5);
    sumList(intList);     // ✅ 可以
    sumList(doubleList);  // ✅ 可以
}
```

### 通配符的 PECS 原则

**PECS (Producer Extends, Consumer Super)**：

```java
public class PECSPrinciple {
    
    // 生产者（读取）：使用 ? extends T
    public static <T> T getFirst(List<? extends T> list) {
        return list.get(0);  // 安全读取
    }
    
    // 消费者（写入）：使用 ? super T
    public static <T> void addLast(List<? super T> list, T element) {
        list.add(element);  // 安全写入
    }
    
    // 既读又写：使用明确的类型 T
    public static <T> void process(List<T> list) {
        T first = list.get(0);  // 读取
        list.add(first);        // 写入
    }
    
    // 实际应用场景
    public static void demo() {
        List<? extends Integer> producer = Arrays.asList(1, 2, 3);
        Integer val = producer.get(0);  // 读：安全
        // producer.add(4);  // 写：不安全
        
        List<? super Integer> consumer = new ArrayList<>(Arrays.asList(1));
        consumer.add(2);  // 写：安全
        // Integer v = consumer.get(0);  // 读：只能得到 Object
    }
}
```

## 类型擦除

### 什么是类型擦除

Java 泛型在编译后会**擦除类型参数**，替换为原始类型或边界类型。

```java
// 编译前
List<String> stringList = new ArrayList<>();
List<Integer> intList = new ArrayList<>();

// 编译后（类型擦除）
List stringList = new ArrayList();
List intList = new ArrayList();
// 两者类型相同！
```

### 擦除规则

```java
// 规则一：无限定的类型参数 → Object
// 编译前: <T>
// 编译后: Object

// 规则二：上界限定 → 上界类型
// 编译前: <T extends Number>
// 编译后: Number

// 规则三：多上界限定 → 第一个上界
// 编译前: <T extends Number & Comparable<T>>
// 编译后: Number

// 示例
public class TypeErasure<T extends Number & Comparable<T>> {
    private T value;
    
    // 编译后：private Number value;
    
    public T getValue() {
        return value;
    }
    // 编译后：public Number getValue()
    
    public void setValue(T value) {
        this.value = value;
    }
    // 编译后：public void setValue(Number value)
}
```

### 类型擦除的影响

```java
public class ErasureImpact {
    
    // 影响一：无法在运行时获取类型参数信息
    public void testRuntimeType() {
        List<String> list = new ArrayList<>();
        // list.getClass() 只能得到 ArrayList.class
        // 无法知道它是 List<String> 还是 List<Integer>
    }
    
    // 影响二：无法创建泛型数组
    public void testGenericArray() {
        // T[] array = new T[10];  // 编译错误！
    }
    
    // 影响三：无法使用泛型类型做 instanceof
    public void testInstanceOf() {
        List<String> list = new ArrayList<>();
        // if (list instanceof List<String>)  // 编译警告
        if (list instanceof List) {  // 只能这样用
        }
    }
    
    // 影响四：无法重载仅泛型不同的方法
    // void process(List<String> list) {}
    // void process(List<Integer> list) {}  // 编译错误！类型擦除后签名相同
}
```

### 绕过类型擦除的方法

```java
public class ErasureWorkaround {
    
    // 方法一：传递类型信息（Class<T>）
    public class TypeSafeBox<T> {
        private final Class<T> type;
        private T value;
        
        public TypeSafeBox(Class<T> type) {
            this.type = type;
        }
        
        public T getValue() {
            return value;
        }
        
        public void setValue(T value) {
            this.value = value;
        }
        
        public Class<T> getType() {
            return type;
        }
        
        // 可以做类型检查
        public boolean isType(Object obj) {
            return type.isInstance(obj);
        }
    }
    
    // 方法二：使用反射获取泛型信息（仅对非泛型类有效）
    public class TypeReference<T> {
        private final Type type;
        
        protected TypeReference() {
            Type superclass = getClass().getGenericSuperclass();
            if (superclass instanceof Class) {
                throw new RuntimeException("Missing type parameter.");
            }
            ParameterizedType pt = (ParameterizedType) superclass;
            this.type = pt.getActualTypeArguments()[0];
        }
        
        public Type getType() {
            return type;
        }
    }
    
    // 使用
    // new TypeReference<List<String>>() {}.getType()
}
```

## 泛型与继承

### 继承规则

```java
public class GenericInheritance {
    
    // 泛型类的继承
    public class Base<T> {
        protected T value;
        // ...
    }
    
    // 子类可以保留或指定类型参数
    public class Derived1<T> extends Base<T> {
        // 保留类型参数
    }
    
    public class Derived2 extends Base<String> {
        // 指定具体类型
        // value 自动变为 String 类型
    }
    
    // 泛型接口的继承
    public interface MyInterface<T> {
        T get();
    }
    
    public interface ExtendedInterface<T> extends MyInterface<T> {
        void set(T value);
    }
    
    // 实现类
    public class MyImpl implements ExtendedInterface<Integer> {
        private Integer value;
        
        @Override
        public Integer get() {
            return value;
        }
        
        @Override
        public void set(Integer value) {
            this.value = value;
        }
    }
}
```

### 通配符与多态

```java
public class WildcardPolymorphism {
    
    static class Animal {}
    static class Dog extends Animal {}
    static class Cat extends Animal {}
    
    // 通配符的多态性
    public void testPolymorphism() {
        // List<Dog> 不是 List<Animal> 的子类型！
        List<Dog> dogs = new ArrayList<>();
        // List<Animal> animals = dogs;  // 编译错误
        
        // 但可以使用通配符
        List<? extends Animal> animals = dogs;  // ✅ 正确
        
        // 这是因为如果允许上面的赋值：
        // animals.add(new Cat());  // 就会出错！向狗列表添加了猫
    }
    
    // 安全的方法
    public static void processAnimals(List<? extends Animal> animals) {
        for (Animal animal : animals) {
            System.out.println(animal.getClass().getSimpleName());
        }
        // 不能添加元素到 List<? extends Animal>
    }
}
```

### 类型安全的 API

```java
// 带类型安全的缓存
public class TypeSafeCache {
    private final Map<Class<?>, Object> cache = new ConcurrentHashMap<>();
    
    @SuppressWarnings("unchecked")
    public <T> T get(Class<T> type) {
        return (T) cache.get(type);
    }
    
    public <T> void put(Class<T> type, T value) {
        cache.put(type, value);
    }
    
    // 使用
    // cache.put(String.class, "Hello");
    // String value = cache.get(String.class);
    
    // 带超时的缓存
    private final Map<Class<?>, CacheEntry<?>> timedCache = new ConcurrentHashMap<>();
    
    public <T> T get(Class<T> type, Duration ttl) {
        @SuppressWarnings("unchecked")
        CacheEntry<T> entry = (CacheEntry<T>) timedCache.get(type);
        if (entry != null && !entry.isExpired()) {
            return entry.getValue();
        }
        return null;
    }
    
    private static class CacheEntry<T> {
        private final T value;
        private final LocalDateTime expireAt;
        
        CacheEntry(T value, Duration ttl) {
            this.value = value;
            this.expireAt = LocalDateTime.now().plus(ttl);
        }
        
        boolean isExpired() {
            return LocalDateTime.now().isAfter(expireAt);
        }
        
        T getValue() {
            return value;
        }
    }
}
```
