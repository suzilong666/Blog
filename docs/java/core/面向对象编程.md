# Java 面向对象编程

面向对象编程（OOP）是 Java 的核心思想。本文将详细讲解类与对象、封装、继承、多态、抽象类、接口等核心概念，并深入剖析其底层实现原理。

## 面向对象概述

### 什么是面向对象

面向对象是一种程序设计范式，通过"类"和"对象"来组织代码，模拟现实世界的事物和关系。

**三大核心特性**：
- **封装**：隐藏内部实现，对外提供公共接口
- **继承**：复用父类代码，建立类的层次结构
- **多态**：同一接口，不同实现

### 类与对象的关系

```
类（Class）是对象的模板/蓝图
对象（Object）是类的实例

类比：
  类 = 图纸（描述房子的结构）
  对象 = 根据图纸盖出来的房子
```

## 类与对象

### 定义类

```java
public class Person {
    // 成员变量（属性）
    private String name;
    private int age;
    
    // 静态变量（类变量）
    private static int personCount = 0;
    
    // 构造方法
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
        personCount++;
    }
    
    // 成员方法
    public void introduce() {
        System.out.printf("我是%s，今年%d岁%n", name, age);
    }
    
    // 静态方法
    public static int getPersonCount() {
        return personCount;
    }
}
```

### 创建对象

```java
// 创建对象（实例化）
Person person1 = new Person("张三", 25);
Person person2 = new Person("李四", 30);

// 调用方法
person1.introduce();  // 我是张三，今年25岁
person2.introduce();  // 我是李四，今年30岁

// 静态方法通过类名调用
System.out.println(Person.getPersonCount());  // 2
```

## 封装

### 访问修饰符

Java 提供四种访问修饰符控制成员的可见性：

| 修饰符 | 同类 | 同包 | 子类 | 不同包 |
|--------|------|------|------|--------|
| `private` | ✅ | ❌ | ❌ | ❌ |
| 默认（package-private） | ✅ | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

### 封装的实现

```java
public class BankAccount {
    // 私有成员变量
    private String accountNumber;
    private double balance;
    private String ownerName;
    
    // 构造方法
    public BankAccount(String accountNumber, String ownerName) {
        this.accountNumber = accountNumber;
        this.ownerName = ownerName;
        this.balance = 0.0;
    }
    
    // 公共的 getter 方法
    public String getAccountNumber() {
        return accountNumber;
    }
    
    public double getBalance() {
        return balance;
    }
    
    public String getOwnerName() {
        return ownerName;
    }
    
    // 公共的操作方法（setter 通常不直接暴露）
    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }
    
    public void withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
        }
    }
    
    // 禁止直接修改余额（无 setter）
    // public void setBalance(double balance) { ... }
}
```

### 封装的好处

1. **隐藏实现细节**：外部无需关心内部如何实现
2. **保护数据安全**：只能通过受控的方法访问
3. **提高可维护性**：内部实现改变不影响外部调用
4. **降低耦合度**：减少类与类之间的依赖

## 继承

### 继承基础

```java
// 父类（基类）
public class Animal {
    protected String name;
    protected int age;
    
    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    public void eat() {
        System.out.println(name + " is eating");
    }
    
    public void sleep() {
        System.out.println(name + " is sleeping");
    }
}

// 子类（派生类）
public class Dog extends Animal {
    private String breed;
    
    public Dog(String name, int age, String breed) {
        super(name, age);  // 调用父类构造方法
        this.breed = breed;
    }
    
    // 新增方法
    public void bark() {
        System.out.println(name + " says: Woof!");
    }
    
    // 方法重写
    @Override
    public void eat() {
        System.out.println(name + " the " + breed + " is eating");
    }
}
```

### 继承的特点

- Java 支持单继承（一个类只能继承一个父类）
- 使用 `extends` 关键字
- 子类继承父类的非私有成员
- 子类可以新增成员和方法
- 子类可以重写父类方法

### super 关键字

```java
public class Dog extends Animal {
    public Dog(String name, int age, String breed) {
        super(name, age);  // 必须放在第一行
        // super 可以访问父类成员
    }
    
    @Override
    public void eat() {
        super.eat();  // 调用父类方法
        System.out.println("...as a dog!");
    }
}
```

### 继承链与 Object 类

```java
// 所有类默认继承 Object 类
// Object 类是所有类的根类

public class MyClass {
    // 隐式继承 Object
}

// Object 类的主要方法
// equals(Object obj)  - 比较对象是否相等
// hashCode()          - 返回哈希码
// toString()          - 返回字符串表示
// clone()             - 创建副本
// getClass()          - 获取运行时类
```

## 多态

### 多态的实现

```java
// 父类引用指向子类对象
Animal myDog = new Dog("Rex", 3, "Husky");
Animal myCat = new Cat("Whiskers", 2);

// 调用方法时，执行的是子类重写后的版本
myDog.eat();   // 调用 Dog.eat()
myCat.eat();   // 调用 Cat.eat()

// 多态的好处：统一调用接口
public void feed(Animal animal) {
    animal.eat();  // 不关心具体类型
}

feed(new Dog("Rex", 3, "Husky"));
feed(new Cat("Whiskers", 2));
```

### 多态的三种形式

1. **方法重写（Override）**：子类重新定义父类方法
2. **方法重载（Overload）**：同类中同名方法，参数不同
3. **动态绑定**：运行时根据对象类型选择方法

```java
// 方法重载（编译时多态）
public class Calculator {
    public int add(int a, int b) {
        return a + b;
    }
    
    public double add(double a, double b) {
        return a + b;
    }
    
    public int add(int a, int b, int c) {
        return a + b + c;
    }
}

// 方法重写（运行时多态）
public class Animal {
    public void speak() {
        System.out.println("Animal speaks");
    }
}

public class Dog extends Animal {
    @Override
    public void speak() {
        System.out.println("Dog barks");
    }
}
```

### instanceof 与类型转换

```java
Animal animal = new Dog("Rex", 3, "Husky");

// 安全类型检查
if (animal instanceof Dog) {
    Dog dog = (Dog) animal;  // 向下转型
    dog.bark();
}

// Java 16+ 模式匹配
if (animal instanceof Dog dog) {
    dog.bark();  // 自动转换
}
```

## 抽象类

### 抽象类基础

```java
// 抽象类不能被实例化
public abstract class Shape {
    protected String color;
    
    public Shape(String color) {
        this.color = color;
    }
    
    // 抽象方法（必须由子类实现）
    public abstract double calculateArea();
    
    // 普通方法（可以有实现）
    public void display() {
        System.out.println("This is a " + color + " shape");
    }
}

// 具体子类
public class Circle extends Shape {
    private double radius;
    
    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }
    
    @Override
    public double calculateArea() {
        return Math.PI * radius * radius;
    }
}
```

### 抽象类的特点

- 使用 `abstract` 关键字
- 不能被直接实例化
- 可以包含抽象方法和普通方法
- 子类必须实现所有抽象方法（除非也是抽象类）
- 可以有构造方法、成员变量

## 接口

### 接口基础

```java
// 接口定义行为契约
public interface Drawable {
    void draw();  // 默认是 public abstract
    
    // Java 8+ 默认方法
    default void resize() {
        System.out.println("Resizing...");
    }
    
    // Java 8+ 静态方法
    static Drawable create() {
        return new Circle("red", 5);
    }
    
    // 常量（public static final）
    String VERSION = "1.0";
}

// 实现接口
public class Rectangle implements Drawable {
    private double width, height;
    
    @Override
    public void draw() {
        System.out.printf("Drawing rectangle: %.0fx%.0f%n", width, height);
    }
}
```

### 接口 vs 抽象类

| 特性 | 接口 | 抽象类 |
|------|------|--------|
| 实例化 | ❌ | ❌ |
| 多继承 | ✅ 可实现多个 | ❌ 只能一个 |
| 构造方法 | ❌ | ✅ |
| 成员变量 | 只能是常量 | 任意类型 |
| 方法实现 | Java 8+ 可有默认方法 | 可有普通方法 |
| 使用场景 | 定义行为契约 | 定义公共基类 |

### 接口的多重实现

```java
public interface Flyable {
    void fly();
}

public interface Swimmable {
    void swim();
}

// 实现多个接口
public class Duck implements Flyable, Swimmable {
    @Override
    public void fly() {
        System.out.println("Duck is flying");
    }
    
    @Override
    public void swim() {
        System.out.println("Duck is swimming");
    }
}
```

## 内部类

### 内部类类型

```java
public class OuterClass {
    private int outerField = 10;
    private static int staticField = 20;
    
    // 成员内部类
    public class MemberInner {
        public void accessOuter() {
            System.out.println(outerField);  // 访问外部类成员
            System.out.println(OuterClass.this);  // 引用外部类实例
        }
    }
    
    // 静态内部类
    public static class StaticInner {
        public void accessStatic() {
            System.out.println(staticField);  // 只能访问静态成员
        }
    }
    
    // 方法内部类
    public void methodWithInner() {
        int localVar = 30;
        
        class LocalInner {
            public void display() {
                System.out.println(localVar);  // 访问局部变量（必须是 effectively final）
            }
        }
    }
    
    // 匿名内部类（常用于事件处理）
    public void anonymousInner() {
        Runnable runner = new Runnable() {
            @Override
            public void run() {
                System.out.println("Anonymous class");
            }
        };
    }
}
```

## 对象生命周期

### 对象的创建

```java
public class Person {
    private static int instanceCount = 0;
    
    // 代码块（构造代码块）
    {
        instanceCount++;
        System.out.println("Instance created: " + instanceCount);
    }
    
    // 静态代码块（类加载时执行一次）
    static {
        System.out.println("Person class loaded");
    }
    
    public Person() {
        System.out.println("Person constructor");
    }
}

// 执行顺序：
// 1. 静态代码块（类加载时）
// 2. 构造代码块（每次创建对象）
// 3. 构造方法
```

### 对象的销毁

Java 使用垃圾回收器（GC）自动管理内存，对象在没有引用时会被回收。

```java
// 对象变成垃圾的情况
Person p = new Person();
p = null;  // 原对象变成垃圾

// 引用计数（Java 不使用此算法）
// Java 使用可达性分析算法
```
