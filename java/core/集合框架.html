Java 集合框架 ​

Java 集合框架提供了一套完整的数据结构实现，包括 List、Set、Map、Queue 等。本文将深入讲解各种集合的特点、使用场景以及底层实现原理。

核心接口 ​

接口特点有序性允许重复常用实现
Collection集合根接口---
List有序可重复✅ 索引有序✅ArrayList, LinkedList
Set无序不重复❌❌HashSet, TreeSet
Map键值对取决于实现键不重复HashMap, TreeMap
Queue先进先出✅ 按顺序✅LinkedList, PriorityQueue

List 系列 ​

ArrayList ​

底层实现：动态数组

java
// 创建 ArrayList
List<String> list = new ArrayList<>();

// 添加元素
list.add("Java");
list.add("Python");
list.add("Go");
list.add(1, "JavaScript");  // 在指定位置插入

// 访问元素
String first = list.get(0);  // "Java"
int size = list.size();      // 4

// 修改元素
list.set(0, "Java 17");

// 删除元素
list.remove(0);       // 按索引删除
list.remove("Go");    // 按值删除

// 判断
boolean contains = list.contains("Python");  // true
boolean isEmpty = list.isEmpty();

// 遍历
for (String item : list) {
    System.out.println(item);
}

list.forEach(System.out::println);  // Java 8+

动态扩容机制：

  • 初始容量：10
  • 扩容策略：当元素数超过容量时，容量扩容为原来的 1.5 倍
  • 扩容过程：创建新数组 → 复制元素 → 替换引用
java
// 源码中的扩容逻辑（简化）
void grow(int minCapacity) {
    int newCapacity = oldCapacity + (oldCapacity >> 1);  // 1.5倍
    elementData = Arrays.copyOf(elementData, newCapacity);
}

时间复杂度：

  • get(int index)：O(1) 随机访问
  • add(E e)：平均 O(1)，扩容时 O(n)
  • remove(int index)：O(n)（需要移动元素）

LinkedList ​

底层实现：双向链表

java
LinkedList<String> linkedList = new LinkedList<>();

// 作为 List 使用
linkedList.add("First");
linkedList.add("Second");

// 作为队列使用
linkedList.offer("Third");   // 添加到队尾
linkedList.poll();            // 从队头移除

// 作为双端队列使用
linkedList.addFirst("Head");
linkedList.addLast("Tail");
linkedList.getFirst();
linkedList.getLast();

// 作为栈使用
linkedList.push("Stack");    // 压入栈
linkedList.pop();             // 弹出栈

双向链表结构：

┌─────────┐    ┌─────────┐    ┌─────────┐
│  Head   │    │  Node1  │    │  Node2  │
├─────────┤    ├─────────┤    ├─────────┤
│ prev ←──│←───│ prev    │←───│ prev    │
│         │    ├─────────┤    ├─────────┤
│  value  │    │  value  │    │  value  │
│         │    ├─────────┤    ├─────────┤
│    ───→ next│───→    next│───→    next│
└─────────┘    └─────────┘    └─────────┘
     ↑                                    ↑
   first                                last

时间复杂度：

  • get(int index)：O(n) 需要遍历
  • 头部添加/删除：O(1)
  • 尾部添加/删除：O(1)（有 last 指针）

ArrayList vs LinkedList ​

操作ArrayListLinkedList
随机访问O(1)O(n)
头部插入O(n)O(1)
尾部插入平均 O(1)O(1)
头部删除O(n)O(1)
尾部删除O(1)O(1)
内存占用较小较大（每个节点两个指针）

Set 系列 ​

HashSet ​

底层实现：HashMap + 链表/红黑树

java
Set<String> hashSet = new HashSet<>();

// 添加元素
hashSet.add("Apple");
hashSet.add("Banana");
hashSet.add("Cherry");
hashSet.add("Apple");  // 重复元素，添加失败

// 常用操作
hashSet.size();        // 3
hashSet.contains("Banana");  // true
hashSet.remove("Cherry");
hashSet.isEmpty();

// 遍历
for (String fruit : hashSet) {
    System.out.println(fruit);
}

Hash 冲突与解决：

┌─────────────────────────────────────────────┐
│              HashMap 数组                    │
│  ┌───┬───┬───┬───┬───┬───┬───┬───┐        │
│  │ 0 │ 1 │ 2 │ 3 │ 4 │ 5 │ 6 │ 7 │        │
│  └─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┘        │
│    │   │   │   │   │   │   │   │          │
│    ▼   ▼   ▼   ▼   ▼   ▼   ▼   ▼          │
│  ┌─────┐┌─────┐┌─────┐                     │
│  │Hash ││Hash ││Hash │  ← 链表解决冲突     │
│  │Entry││Entry││Entry│                     │
│  └──┬──┘└──┬──┘└──┬──┘                     │
│     │      │      │                        │
│     ▼      ▼      ▼                        │
│  ┌─────┐┌─────┐┌─────┐                     │
│  │Hash ││Hash ││Hash │                     │
│  │Entry││Entry││Entry│                     │
│  └─────┘└─────┘└─────┘                     │
└─────────────────────────────────────────────┘
    ↑ 当链表长度 ≥ 8 时，转为红黑树

特点：

  • 无序（元素顺序不可预测）
  • 允许 null 值
  • 添加/删除/查找：平均 O(1)
  • 线程不安全

TreeSet ​

底层实现：红黑树

java
Set<String> treeSet = new TreeSet<>();

// 自动排序
treeSet.add("Cherry");
treeSet.add("Apple");
treeSet.add("Banana");
// 结果: [Apple, Banana, Cherry]

// 自定义排序
Set<Integer> customSet = new TreeSet<>(Comparator.reverseOrder());
customSet.add(3);
customSet.add(1);
customSet.add(2);
// 结果: [3, 2, 1]

// 自定义对象排序
Set<Person> personSet = new TreeSet<>((p1, p2) -> 
    p1.getName().compareTo(p2.getName())
);

特点：

  • 有序（默认自然排序或自定义排序）
  • 不允许 null 值
  • 添加/删除/查找：O(log n)
  • 线程不安全

LinkedHashSet ​

底层实现：HashMap + 双向链表

java
Set<String> linkedHashSet = new LinkedHashSet<>();

// 保持插入顺序
linkedHashSet.add("First");
linkedHashSet.add("Second");
linkedHashSet.add("Third");
// 遍历时保持: First, Second, Third

特点：

  • 有序（保持插入顺序）
  • 允许 null 值
  • 添加/删除/查找：平均 O(1)

Map 系列 ​

HashMap ​

底层实现：数组 + 链表 + 红黑树（JDK 8+）

java
Map<String, Integer> hashMap = new HashMap<>();

// 添加元素
hashMap.put("Apple", 1);
hashMap.put("Banana", 2);
hashMap.put("Cherry", 3);
hashMap.putIfAbsent("Apple", 100);  // 仅当 key 不存在时添加

// 获取元素
int value = hashMap.get("Apple");  // 1
int defaultValue = hashMap.getOrDefault("Grape", 0);  // 0

// 删除元素
hashMap.remove("Banana");
hashMap.remove("Cherry", 3);  // 仅当 key-value 匹配时删除

// 遍历 Map
for (Map.Entry<String, Integer> entry : hashMap.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue());
}

// 使用 Lambda
hashMap.forEach((key, val) -> System.out.println(key + ": " + val));

// 判断
hashMap.containsKey("Apple");
hashMap.containsValue(1);
hashMap.isEmpty();
hashMap.size();

HashMap 内部结构：

┌───────────────────────────────────────────────────────────┐
│                          HashMap                            │
│  ┌─────────────────────────────────────────────────────┐  │
│  │  Node<K,V>[] table (哈希表数组)                      │  │
│  │  ┌───┬───┬───┬───┬───┬───┬───┬───┬───┬───┐        │  │
│  │  │ 0 │ 1 │ 2 │ 3 │ 4 │ 5 │ 6 │ 7 │...│n  │        │  │
│  │  └─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬─┴─┬───┴───┘        │  │
│  │    │   │   │   │   │   │   │   │   │               │  │
│  │    ▼   ▼   ▼   ▼   ▼   ▼   ▼   ▼   ▼               │  │
│  │  ┌─────┐┌─────┐┌─────┐                              │  │
│  │  │Node ││Node ││Node │                              │  │
│  │  │     ││     ││     │                              │  │
│  │  │hash ││hash ││hash │                              │  │
│  │  │key  ││key  ││key  │                              │  │
│  │  │value││value││value│                              │  │
│  │  │next─┼│next─┼│next─┼──→ 链表                     │  │
│  │  └─────┘└─────┘└─────┘                              │  │
│  └─────────────────────────────────────────────────────┘  │
│                                                           │
│  关键参数:                                                 │
│  - DEFAULT_INITIAL_CAPACITY = 16 (初始容量)               │
│  - DEFAULT_LOAD_FACTOR = 0.75f (负载因子)                 │
│  - TREEIFY_THRESHOLD = 8 (树化阈值)                       │
│  - UNTREEIFY_THRESHOLD = 6 (树退化阈值)                   │
│  - MIN_TREEIFY_CAPACITY = 64 (最小树化容量)               │
└───────────────────────────────────────────────────────────┘

扩容机制：

  • 当 size > capacity × loadFactor 时触发扩容
  • 容量翻倍（2 倍）
  • 所有元素重新计算哈希位置

哈希冲突解决：

  1. 通过 (n-1) & hash 计算数组位置
  2. 链表存储冲突元素
  3. 当链表长度 ≥ 8 且数组长度 ≥ 64 时，转为红黑树
  4. 当红黑树节点 ≤ 6 时，退化为链表

TreeMap ​

底层实现：红黑树

java
Map<String, Integer> treeMap = new TreeMap<>();

// 按键排序
treeMap.put("Cherry", 3);
treeMap.put("Apple", 1);
treeMap.put("Banana", 2);
// 结果按 key 排序: Apple, Banana, Cherry

// 范围操作
NavigableMap<String, Integer> subMap = treeMap.subMap("Apple", "Cherry");
NavigableMap<String, Integer> headMap = treeMap.headMap("Banana", true);
NavigableMap<String, Integer> tailMap = treeMap.tailMap("Banana", false);

// 首尾元素
treeMap.firstEntry();
treeMap.lastEntry();
treeMap.pollFirstEntry();
treeMap.pollLastEntry();

LinkedHashMap ​

底层实现：HashMap + 双向链表

java
Map<String, Integer> linkedHashMap = new LinkedHashMap<>();

// 保持插入顺序
linkedHashMap.put("First", 1);
linkedHashMap.put("Second", 2);
linkedHashMap.put("Third", 3);
// 遍历时保持: First, Second, Third

// 访问顺序（LRU 缓存）
Map<String, Integer> lruCache = new LinkedHashMap<>(16, 0.75f, true) {
    @Override
    protected boolean removeEldestEntry(Map.Entry<String, Integer> eldest) {
        return size() > 100;  // 最多缓存 100 个
    }
};

ConcurrentHashMap ​

底层实现：分段锁（JDK 7）+ CAS + synchronized（JDK 8）

java
// 线程安全的 Map
Map<String, Integer> concurrentMap = new ConcurrentHashMap<>();

// 支持并发访问
concurrentMap.put("key1", 1);
concurrentMap.get("key1");
concurrentMap.remove("key1");

// 原子操作
concurrentMap.computeIfAbsent("key", k -> expensiveOperation(k));
concurrentMap.computeIfPresent("key", (k, v) -> v + 1);

JDK 8+ 改进：

  • 使用 CAS + synchronized 替代分段锁
  • 锁粒度更小（锁单个链表头节点）
  • 并发性能大幅提升

集合选择指南 ​

选择决策树 ​

需要存储什么？
├── 键值对 → Map
│   ├── 键有序 → TreeMap
│   ├── 需要保持插入顺序 → LinkedHashMap
│   ├── 线程安全 → ConcurrentHashMap
│   └── 普通 → HashMap
│
└── 单值 → Collection
    ├── 需要有序？
    │   ├── 需要随机访问 → List
    │   │   ├── 普通 → ArrayList
    │   │   └── 频繁头部操作 → LinkedList
    │   └── 不需要随机访问 → Set
    │       ├── 需要排序 → TreeSet
    │       ├── 需要保持插入顺序 → LinkedHashSet
    │       └── 普通 → HashSet
    │
    └── 需要先进先出 → Queue
        ├── 普通队列 → LinkedList
        ├── 优先级队列 → PriorityQueue
        └── 双端队列 → ArrayDeque

性能对比 ​

集合类型添加删除查找内存

最佳实践 ​

初始容量设置 ​

java
// 预估元素数量，设置合适初始容量
int expectedSize = 1000;
// HashMap 容量应大于 expectedSize / 0.75
Map<String, Object> map = new HashMap<>(expectedSize * 2);

// ArrayList 同理
List<String> list = new ArrayList<>(expectedSize);

不可变集合 ​

java
// 创建不可变集合（Java 9+）
List<String> immutableList = List.of("A", "B", "C");

Map<String, Integer> immutableMap = Map.of("key", 1);

// 旧方式
List<String> oldStyle = Collections.unmodifiableList(
    new ArrayList<>(list)
);

java
import java.util.Collections;

// 排序

int index = Collections.binarySearch(sortedList, target);
